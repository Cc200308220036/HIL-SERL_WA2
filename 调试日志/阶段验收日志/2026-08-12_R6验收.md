## 1. 一句话结论

R6 把 Env 的图像从「Mock / 零图占位」升级为 **ROS 双路真图**（头 + 左腕）：订机载 topic → 解码为 RGB → 可选 crop → resize 到 `128×128` → 写入 `obs["images"]`；任一路超时则 `truncated`。不在 Env 内二次打开 USB，避免与机载 RealSense 驱动抢设备。

## 3. Env 改进：含义与用法

### 3.1 改进含义（相对 R5）

| 之前（R5 及以前） | 现在（R6） |
|---|---|
| `fake_env=False` 时图像仍多为 `MockCameras` | 真机自动用 `WA2Cameras`，订头+腕 ROS 图 |
| 腕契约 `enabled=false`，obs 腕图常为零 | 腕 `enabled=true`，obs 为真实近景（转 RGB） |
| `info["image_age"]` 常为占位 0 | `image_ages` 分路年龄；`image_age` 取最严一路 |
| 仅状态 stale 可截断 | **头或腕**超 `image_max_age_s`（默认 0.2s）→ `truncated`；运动模式另 stop+clear |
| Learner/`fake_env` | 仍不订真相机，双键 Mock，shape 不变 |

数据流：

```text
机载 topic (head rgb8 / wrist bgr8)
    → WA2ImageMonitor 订阅 + 预处理
    → WA2Cameras.get_images()
    → obs["images"]["head"|"wrist"]  uint8[128,128,3] RGB
```

### 3.2 构造参数（R6 相关）

```python
from hilserl_wa2.envs.wa2_env import WA2Env

# 真机只读看图（日常调试，不发 ServoL）
env = WA2Env(
    fake_env=False,
    read_only=True,
    camera_cfg_path=None,  # 默认包内 configs/cameras/head_wrist.yaml
)

# 真机运动 + 场景 reset（需 R4/R5 确认变量）
env = WA2Env(
    fake_env=False,
    read_only=False,
    scene_name="bottle_desktop",
)

# Learner / 单测：绝不碰相机
env = WA2Env(fake_env=True, seed=0)
```

| 参数 | 含义 |
|---|---|
| `fake_env=True` | Mock 状态+图；**忽略** `camera_cfg_path` |
| `fake_env=False` | 接 ROS；图像走 `WA2Cameras` |
| `camera_cfg_path` | 可选，指向自定义双相机 YAML |
| `cameras=` | 可注入已有相机对象（单测/脚本） |
| `read_only` | 只读时不发 ServoL，但仍订真图 |

### 3.3 reset / step / close 行为

**`reset(options=...)`（真机）**

1. 状态 Monitor 就绪  
2. 相机 `start()` + `wait_ready()`（可用 `camera_ready_timeout_s`）  
3. 若带 `scene_name` 且非只读：R5 MoveJ reset  
4. 再开 ServoL 会话（非只读）  
5. 返回的 `obs["images"]` 已是最新 128 图  

常用 options：

```python
env.reset(options={
    "skip_reset_motion": True,   # 只读采图时跳过 MoveJ
    "ready_timeout_s": 8.0,
    "camera_ready_timeout_s": 8.0,
})
```

**`step(action)`**

- 合并 `state` stale 与 `images/head`、`images/wrist` stale  
- 任一路图像过期 → `truncated=True`，`info["stale_fields"]` 含 `images/head` 或 `images/wrist`  
- 非只读时图像/状态异常会走 ServoL `stop+clear`  

**`close()`**

- 停 ServoL（若有）→ 停状态订阅 → **停相机订阅**

### 3.4 观测与 info 字段

```text
obs["images"]["head"]   # uint8 (128,128,3) RGB
obs["images"]["wrist"]  # uint8 (128,128,3) RGB

info["image_ages"]      # {"head": 秒, "wrist": 秒}
info["image_age"]       # 两路年龄的最大值（最严）
info["wrist_enabled"]   # True（v0.1.1）
info["stale_fields"]    # 如 ["images/wrist"]
```
