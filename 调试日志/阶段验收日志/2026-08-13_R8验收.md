## 3. 实施中相对方案的必要调整

1. `mappings.py` **中 Franka 实验改为可选导入。** 本容器没有 `franka_env`，硬 import 会导致 `CONFIG_MAPPING` 无法加载 WA2。WA2 扫描注册不受影响。
2. **禁止** `encoder_type=resnet` **回退。** 当前 serl `EncodingWrapper` 会向 encoder 传 `encode=`，scratch ResNet 不接受该参数。Agent Gate 使用已下载的 `~/.serl/resnet10_params.pkl`。

### 5.4 常见故障


| 现象                                            | 处理                                              |
| --------------------------------------------- | ----------------------------------------------- |
| `No module named hilserl_wa2` / `experiments` | 检查上面三条 `PYTHONPATH`                             |
| `wa2_bottle_pick` 不在 mapping                  | YAML 是否在 `configs/tasks/`，`task_id` 是否等于文件名     |
| `No module named franka_env`                  | 应已被 mappings 可选导入吞掉；若仍出现，确认用的是当前 `mappings.py`  |
| fake_env 却初始化 ROS                             | factory 误走了真机分支；确认 `fake_env=True`              |
| `state` shape 是 `(27,)`                       | 漏了 `ChunkingWrapper`                            |
| agent `unexpected keyword encode`             | 误用了 `encoder_type=resnet`；改回 pretrained 并确认 pkl |
| agent 缺 pkl                                   | 见方案 §4.8 的 curl 命令（容器内 `~/.serl/`）              |
| `WA2_TASK` mismatch                           | 去掉环境变量，或与任务参数一致                                 |
