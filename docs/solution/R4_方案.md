## 2. 架构与冻结语义

### 2.1 数据流

```text
action[-1,1]^6
    │
    ▼
WA2Env(fake_env=False, read_only=False)
    ├─ StateMonitor（R3）读状态 / ages / singular
    ├─ MockCameras（图像仍 Mock，R6 再换）
    └─ WA2ServoSession（本阶段新增，唯一出口）
            ├─ start(): set_servo_params(0.02, 800, left)
            ├─ apply_normalized_action(action, dt=0.02)
            │     clip → 物理增量 → 限幅 → workspace → servol(left)
            ├─ stop() / clear() / close()
            └─ health(): stale? singular? publishers?
```

控制权原则（强制）：

```text
SpaceMouse / 策略 / 测试脚本
  → 只产生 Env action
  → 仅 WA2ServoSession 发布 /zj_humanoid/upperlimb/servol/left_arm
禁止并行：spacemouse_wa2_teleop.py、临时 servol 测试脚本
```

### 2.2 契约限幅（不得擅自放大做 Gate）

```text
action: 6D float32 [-1,1]
position_frame: base
rotation_frame: tool
max_pos_delta_m: 0.001          # 每步 ≤ 1.0 mm
max_rot_delta_deg: 0.25         # 每步 ≤ 0.25°
control_dt: 0.02                # 50 Hz
servo_time: 0.02
servo_gain: 800
state_max_age_s: 0.2
```

说明：真机 Gate「Roll/Pitch/Yaw ±2°」通过 **多步累计**（约 `2/0.25=8` 步满幅）完成，禁止把单步上限改成 2°。

### 2.3 安全分层

| 层 | 内容 |
|---|---|
| L0 单步 | clip + `max_pos_delta` / `max_rot_delta` |
| L1 episode box | 相对 reset 原点的位移/转角上限（建议先：平移 30 mm，旋转 5°） |
| L2 全局 box | 可选绝对 TCP 软边界（配置化；首版可先关，但接口预留） |
| L3 门控 | stale / singular / 未 start / 已 faulted → 拒绝发目标并 stop/clear |

## 4. 实现规格

### 4.1 `WA2ServoSession`

```text
WA2ServoSession
  __init__(arm="left", contract, state_monitor, dry_run=False,
           episode_trans_limit_m=0.03, episode_rot_limit_deg=5.0)
  start()
  apply_normalized_action(action[6], dt=None) -> info
  stop() -> bool
  clear() -> bool
  health() -> dict
  close()          # stop+clear；幂等
```

必须：

1. `start()` 调用 `set_servo_params(time=0.02, gain=800, arm=left)`；  
2. **仅一处** action→TCP 目标转换（可复用 `PoseIntegrator` 或与 MockRobot 同公式，禁止复制第三套）；  
3. `apply` 前检查：`started`、`not faulted`、`state fresh`、`not singular`；  
4. 失败路径：置 `faulted=True` → `stop()` → `clear()` → 后续 `apply` 直接拒绝；  
5. `info` 记录：`cmd_tcp`、`meas_tcp`、`tracking_err_m`、`tracking_err_rad`、`loop_dt`、`clipped_action`；  
6. `dry_run=True` 时只计算不 `publish`；  
7. 不在此类里做手部控制。

发布接口优先走已有 `naviai_controller.ArmController.servol` / `set_servo_params` / `stop` / `clear_servo_params`，但：

- Session 外禁止散落 publish；  
- Env / Gate 脚本只持有一个 Session 实例。

### 4.2 `WA2Env` 扩展

```python
WA2Env(
  fake_env=False,
  read_only=False,   # R4
  dry_run=False,
  ...
)
```

| 模式 | 行为 |
|---|---|
| `fake_env=True` | R2 Mock（回归） |
| `read_only=True` | R3 只读（回归） |
| `read_only=False` | R4：`step` → ServoSession.apply |

`step` 伪码：

```text
validate/clip action
if stale or singular: stop/clear; truncated=True; return
applied = servo.apply_normalized_action(action)
obs = state_monitor + mock cameras
reward = 0
truncated |= max_steps | faulted
info 合并 servo tracking + ages + read_only=False
```

`close()` / 析构 / 信号：必须 `servo.close()`（stop+clear）。

## 6. 验收标准（Gate R4）

**全部满足方可进入 R5。**

### 6.1 控制权与安全

- [ ] 同一时刻 **只有一个** ServoL 发布者（本 Env/Session）  
- [ ] 异常 / Ctrl+C / `close` 后：`stop=True` 且 `clear=True`，不再发新目标  
- [ ] stale（>0.2s）或 singular 时拒绝新目标并 stop/clear  
- [ ] 未设 `R4_CONFIRM=YES` 时真机脚本拒绝运动  

### 6.2 运动正确性

- [ ] **零 action 保持**：建议 5 s 内 TCP 漂移 &lt; 2 mm（记实测）  
- [ ] **X/Y/Z ±1 mm**：方向正确；跟踪误差满足约定（建议位置误差 &lt; 1 mm 量级，记实测）  
- [ ] **Roll/Pitch/Yaw 累计 ±2°**：方向正确；轴外旋转与位置漂移不高于 0810 基线量级  
- [ ] **clip**：超界 action 的物理增量仍 ≤ 契约单步上限  
- [ ] 每步不超过单步限幅与 episode workspace  

### 6.3 软件回归

- [ ] `unittest discover .../tests/unit` 全部 PASS  
- [ ] `verify_r2_mock_env.py` → `R2 GATE: PASS`  
- [ ] `verify_r3_readonly_env.py` → `R3 GATE: PASS`  
- [ ] `verify_r4_servo_dryrun.py` → `R4_DRYRUN: PASS`  
- [ ] 真机 gates 脚本输出 `R4 GATES: PASS`（或分 gate 全 PASS）

## 8. 风险与注意

1. **失能 / 奇异**：R3 采样时曾见 `left_arm_is_singular=True`；R4 开跑前必须为 False，否则先人工脱困。  
2. **禁止并行遥操**：双发布者会导致不可控竞争。  
3. **单步上限不可为图快改契约**：±2° 用多步累计。  
4. **首次真机**先 Gate A（保持），再单轴平移，最后旋转。  
5. **图像仍 Mock**：不阻塞 R4；R6 再换真实相机。  
6. 若机器人进入故障/失能：先 `stop` + `clear`，按厂家流程上使能，**不要**在故障态继续 Gate。
