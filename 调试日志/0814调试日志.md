## 3. 两端边界（强制）

两端不是「同一仓库换个 IP」，而是 **两套运行树 + 一份共享语义副本**。

| 角色 | 唯一运行根 | Conda | 本端允许启动 | 禁止 |
|---|---|---|---|---|
| **Learner** | 笔记本 `/home/cyw/orin_hilserl/HILSERL_Learner` | `hil-learner` / 3.10.20 | `r10_learner_server.py`、依赖/GPU 检查 | 启动 `verify_r10_actor_remote.py`、R3–R9 真机脚本、把 `catkin_ws` 当 Learner 根 |
| **Actor** | Orin 容器 `/root/catkin_ws` | `hil-actor` | `verify_r10_actor_remote.py`、R9 回归 | 启动 `r10_learner_server.py`、`source activate_hil_learner.sh` |
| **分析根** | 笔记本 `/home/cyw/orin_hilserl`；Orin `/home/naviai/hilserl_orin` | — | 看文档与同步副本 | 不是 Python 运行根 |

同步规则：

- 共享语义文件：改一处，按**相对路径**复制到另一端，再对白名单算 `source_tree_sha256`。
- 只同步白名单和 `local.yaml`。**禁止**整棵 `HILSERL_Learner/` rsync 到 Orin，也禁止整棵 `catkin_ws` 当 Learner。
- `local.yaml` **只在笔记本生成**，再拷到 Actor 同一相对路径；禁止两端各填一份 IP。

固定 IP / 端口：

```text

端口：TCP 5588（请求）/ 5589（参数广播）
```

**单测证据**（容器 `hil-actor`）：

```text
test_r9_transition + test_r9_actor_safety + test_r10_protocol + test_r10_recovery
Ran 45 tests in 0.150s
OK
```

`test_r10_recovery` 核心覆盖：拒回环/Docker bridge IP；handshake mismatch → `ENV_STEPS=0`；Server 重启旧 session 作废；fault dump；重传靠 `session_id+stream+sequence_id`；白名单不含 `local.yaml`。

回环冒烟（必须失败）：

```text
R10_ACTOR: FAIL — rejects loopback ... '127.0.0.1'
```

**联机时 Actor 行为（协议要点）：**

1. 读同一份 `local.yaml` + `actor_manifest.json`  
2. Client 连笔记本 5588/5589（`wa2-r10-v1`；request：`send-stats` / `r10-handshake` / `r10-status` / `r10-ping`）  
3. **`env.reset/step` 前**握手；失败则不收数、不广播  
4. 等 Learner **周期重发** params；签名一致才 `agent.replace`  
5. 上传后用 `r10-status` 对 count / last id / ordered digest  
6. 停 Server → `FAULT_REASON=network_loss`，`AUTO_RECONNECT=false`，写 dump  

### 4.4 联调前踩过的坑

| 问题 | 影响 | 处理 |
|---|---|---|
| `network_max_age_s: 5`（int） | Server 报 `network_config_hash` 与 manifest 不一致，F0 起不来 | 改回 `5.0`，与冻结 manifest 对齐 |

| 容器内 `$R10_LEARNER_IP` 为空 / 无 `nc` | 连错或探端口失败 | 容器必须 export `172.16.9.36`；宿主机 `nc` 或 Python 探测 |
