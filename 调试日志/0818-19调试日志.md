## 4. 问题 → 原因 → 处理（按时间线）



### 4.1 训练 Gate：val 选不出合法阈值 / test P 不够


| 现象                                                     | 原因                                                | 处理                                                            |
| ------------------------------------------------------ | ------------------------------------------------- | ------------------------------------------------------------- |
| 首轮 live 训：test 尚可，但 `VAL_CONSTRAINT_OK=false`，阈值兜底 0.5 | val 上无 P≥0.85 候选                                  | 补 hardneg，改选阈值为 val 上 P≥0.85 中最大化 **Fβ(β=0.5)**               |
| 合并 hardneg / v2～v5 后 test P 仍常 <0.85（如 0.68～0.75）      | 假阳性：爪仍在瓶/册附近却像「放好」；成功样本偏少且口径松                     | 多次补「像成功的失败」；`reselect` 打印 `TEST_THRESHOLD_SWEEP` / FP episode |
| 导出 FP 画面（`debug_fp_v5`）                                | 8 个 FP 集中在旧 live-ep-009 与 hardneg-ep-001；白瓶白爪对比度低 | 明确成功须 **手投影离开**；难失败仿这两局                                       |
| 补 50 成功+50 失败后：P≈0.91 过、R≈0.67 挂                       | 成功偏严/偏少样 → 漏检                                     | 再补干净成功；但随后 60+20 又把 P/R 搅乱                                    |
| 叠包指标乱抖                                                 | 标注口径前后不一致 + episode 重划                            | **放弃叠包**，改干净重采                                                |


**教训：** 只调阈值过不了 Gate；无限 `merged_vN` 不如 **统一标注 + 足够换局的单包**。

### 4.2 Learner 评估 OOM


| 现象                                        | 原因                     | 处理                                                                        |
| ----------------------------------------- | ---------------------- | ------------------------------------------------------------------------- |
| 150 epoch 训完，写 metrics 前 GPU OOM（~588MiB） | `predict_probs` 整集一次前向 | train / reselect / eval_splits 改为 **batch=16** 分批推理；ckpt 已写出时可只跑 reselect |




### 4.3 干净重采第一包：test 全 0 / val 无成功


| 现象                                                                                       | 原因                                      | 处理                                                                        |
| ---------------------------------------------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------- |
| `clean_59b6d310`：100/200 但仅 **3 episode**；`TEST_CONFUSION` 全 0；`VAL_CONSTRAINT_OK=false` | 按 `episode_id` 划分：局太少时 test 空、val 可能无正类 | 同标准重采 `9a7e147d`**：100/201/14ep** → **R12_TRAIN: PASS**（P=R=1.0，thr=0.85） |


**教训：** 快照标对 ≠ Gate 可信；换局次数决定划分是否可评。

### 4.4 Step8 scp Permission denied


| 现象                                | 原因                 | 处理                                                  |
| --------------------------------- | ------------------ | --------------------------------------------------- |
| `naviai@` scp 写不上 Orin `runs/...` | 目录属 **root**（容器创建） | 宿主机 `chown -R naviai` 后再 scp，或 `/tmp` + `docker cp` |




### 4.5 Step9：JAX/XLA 在 Orin Abort


| 现象                                                        | 原因                          | 处理                                                                                           |
| --------------------------------------------------------- | --------------------------- | -------------------------------------------------------------------------------------------- |
| `cudaGetFuncBySymbol: no kernel image...` 于 conv autotune | Orin 上 XLA GPU autotune 不兼容 | `eval_r12_live` / `reward_classifier` 启动前 `XLA_FLAGS=--xla_gpu_autotune_level=0`（与 R8/R9 一致） |




### 4.6 Step9：不能张合手爪


| 现象     | 原因                                    | 处理                                                             |
| ------ | ------------------------------------- | -------------------------------------------------------------- |
| 只能推杆移动 | eval 未接采集脚本的右键 `request_hand(toggle)` | `eval_r12_live.py` 补 `_AsyncHandToggle`（LEFT=session，RIGHT=张合） |




### 4.7 Step9：hold 立刻 FAIL（episode ended）


| 现象                           | 原因                                                                      | 处理                                        |
| ---------------------------- | ----------------------------------------------------------------------- | ----------------------------------------- |
| `RESET_CALLED=false` 但仍 FAIL | 标注久了踩到 scene **max_steps=4000** soft truncate；eval 把任意 truncated 当 FAIL | 对齐采集：软截断只告警，**仅** fault/`terminated` 判硬失败 |
