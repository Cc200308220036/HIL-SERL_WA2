### 1.2 上游 `record_demos.py` 为什么不能当入口

```text
Franka 示例：
```

### 1.3 任务成功的现场定义（人工，不是分类器）

`bottle_pick` 一条 **成功** demo 必须同时满足：

1. 本局从 R5 reset 开始，`reset_ok=True`，`is_singular=False`；  
2. 操作员 **点按左键** 进入 SpaceMouse 控制，完成接近 → 右键抓取 → 搬到放置区 → 右键张开；再 **点按左键** 结束本局；  
3. 瓶子被抓起并放到目标区、未掉落、未碰撞；  
4. 结束本局后在终端输入 `s` 保留 / `f` 失败 / `a` 重录；  
5. 本局 `intervened_steps >= 30`（禁止“零干预空转”标成功）；  
6. 本局无 `stale` / 奇异 / `stop` 抢占 / Ctrl+C。

失败/中止（**不得**写入成功 pkl）：

- 操作员输入 `f`（失败）或 `a`（丢弃）；  
- `truncated`（图像/状态 stale、伺服故障；`max_steps=4000` 到点后仍可按 `s`）；  
- Ctrl+C、急停、Env close、网络/ROS 崩溃；  
- 未抓稳或抬起后掉落。

## 2. 目标、非目标与 Action 控制权

### 2.1 目标

1. Actor 在 Orin 用 **zero policy + SpaceMouse 干预** 采集 `bottle_pick` 示范；  
2. 先 5 条 schema Gate，再至少 20 条成功 demo；  
3. 每条成功轨迹的每步都是 R9 transition，且 `actions` 等于实际执行动作（有干预时等于 `intervene_action`）；  
4. 失败/中止写入 `failed/`，永不混入成功 pkl；  
5. 每条轨迹带 sidecar：task/config hash/时间/操作者/步数/干预统计/人工标签；

## 3. 可复用设计与冻结语义

### 3.1 数据流

```text
policy = zeros(6)
    │
    ▼
WA2SpacemouseIntervention
    ├─ 无 deadman → 执行 zero（臂应保持）
    └─ deadman+有效输入 → info["intervene_action"] 覆盖
    │
    ▼
WA2Env.step  （唯一 ServoL）
    │  右键边沿：WA2Env.request_hand(toggle)
    ▼
build_actor_transition(...)     # R9 6 键
    │
    ├─ 本局进行中 → 仅内存 trajectory
    ├─ 人工 s     → 写入成功 pkl + sidecar
    └─ f/a/截断/Ctrl+C → failed/ 或丢弃，绝不进成功文件
```

### 3.2 成功 pkl 格式（给未来 `train_rlpd.py --demo_path`）

一个文件 = **扁平** `list[dict]`，每条 dict 仅含：

```python
{
    "observations": {"state": (1,27), "head": (1,128,128,3), "wrist": (1,128,128,3)},
    "actions": float32[6],          # 实际执行动作
    "next_observations": {同上},
    "rewards": float32(0.0),        # 禁止写成 1.0
    "masks": float32,               # terminated→0 否则 1
    "dones": bool,                  # 仅人工成功的最后一步可为 True
}
```

约定：操作员按 `s` 时，**仅最后一步** 标 `terminated=True`（`dones=True`, `masks=0`），表示人工成功结束，不是分类器 reward。中间步全部 `dones=False`, `masks=1`。

禁止把多条轨迹的 metadata 塞进 pkl。元数据在 sidecar。

### 3.3 目录布局

同一 `R11_RUN_ID` 会先后产生 fake5 / live5 / live20，**禁止**共用一个 `wa2_bottle_pick_5_schema_*.pkl` 文件名，也 **禁止** 把全部 sidecar 平铺进同一个 `demos/episodes/` 再让 Learner 按目录计数。每个验收包是独立 bundle：

```text
<ROOT>/runs/wa2_bottle_pick/<R11_RUN_ID>/
  actor_manifest.json          # 或 learner_manifest.json（仅归档）
  network_config.yaml          # 仅归档，本阶段不连 Server
  operator_log.md              # 人工记录：条数、成败、异常
  demos/
    wa2_bottle_pick_5_fake_<uuid>/
      demo.pkl
      bundle.json              # n_episodes、pkl 相对路径、sidecar 列表
      SHA256SUMS               # 相对本 bundle 目录：demo.pkl + episodes/*.json + bundle.json
      episodes/ep000.json ...
    wa2_bottle_pick_5_live_<uuid>/
      ...同上...
    wa2_bottle_pick_20_success_<uuid>/
      ...同上...
  failed/
    epXXX.pkl + epXXX.json     # 失败/中止，不入库；Learner 默认不拷
  logs/
    record.log
    load_fake5.log             # Learner 写入 Learner 树
    load_live5.log
    load_live20.log
```

Actor `<ROOT>` = `/root/catkin_ws`  
Learner `<ROOT>` = `/home/cyw/orin_hilserl/HILSERL_Learner`  
宿主机可见 Actor 产出：`/home/naviai/hilserl_orin/catkin_ws/runs/wa2_bottle_pick/<R11_RUN_ID>/`

`bundle.json` 最低字段：

```json
{
  "bundle_name": "wa2_bottle_pick_5_fake",
  "pkl": "demo.pkl",
  "n_episodes": 5,
  "label": "success",

```

Learner 对账只读 **当前 `--bundle-dir`**，不得扫描整个 `demos/` 或整个 `episodes/`。

`record_r11_demos.py` 建议 CLI：

```bash

  --task bottle_pick \
  --run-dir "$R11_ACTOR_RUN" \
  --operator "$USER" \
```

`verify_r11_demo_load.py` 建议 CLI（**只接受一个 bundle 目录**，禁止 `--pkl` glob 多文件）：

```bash
python .../verify_r11_demo_load.py \
  --task bottle_pick \
  --bundle-dir "$BUNDLE" \
  --expect-episodes 5 \
  --run-dir "$R11_LEARNER_RUN" \
  --batch-size 8
```

硬规则（实现时写入脚本，不靠操作员记）：

- `--bundle-dir` 必须是目录，内含 `demo.pkl` + `bundle.json` + `episodes/`；路径中含 `failed/` 立即 FAIL。  
- 只打开这一个 pkl；shell glob 若匹配到多个路径必须退出。  
- 默认就做：6 键 schema、`process_demos` 恒等、`MemoryEfficientReplayBufferDataStore` insert、`sample`。  
- **禁止**按 `bottle_pick.yaml` 的 `replay_buffer_capacity=200000` 或 `batch_size=256` 建满 Buffer（16G 笔记本会先 OOM；5 条 schema 的 transition 总数也可能 `<256`）。容量用 `n_transitions + 32`；`--batch-size` 默认 8，且必须 `<=` 可 sample 条数。  
- 不初始化 SAC、不广播 params、不监听 5588/5589。  
- `--expect-episodes N` 表示 `n_episodes >= N`（live20 可多采）；计数只来自当前 bundle，不是整个 run。 
- `WA2TrainConfig.process_demos` 必须恒等；上游 `train_rlpd.py` 当前也不调用它，R11 仍要测这个桩，避免 R13 误改。
