### 0.3 当前 Env 有哪些内容（R1～R5 累计）

```text
WA2Env
├─ 契约 WA2EnvContract          # R1：obs/action/限幅/新鲜度
├─ 场景 WA2SceneConfig（可选）  # R5：home/腰/TCP/手/超时/max_steps

├─ WA2StateMonitor              # R3：ROS 只读状态
├─ WA2ServoSession              # R4：唯一 ServoL 出口
└─ WA2ResetExecutor             # R5：reset 运动与门控
```


| 模式         | 构造                                | 状态来源                    | 运动              | 典型用途            |
| ---------- | --------------------------------- | ----------------------- | --------------- | --------------- |
| Mock       | `fake_env=True`                   | MockRobot（可落到 scene 姿态） | 否（积分模拟）         | 单测 / Learner    |
| ROS 只读     | `fake_env=False, read_only=True`  | StateMonitor            | 否               | 接真机状态、不发控       |
| ServoL 真机  | `fake_env=False, read_only=False` | Monitor + Session       | 是（需确认 env）      | Gate / 训练 Actor |
| + 场景 reset | 再加 `scene_name=...`               | 同上                      | reset 时 MoveJ/手 | **可重复 episode** |


已冻结接口语义（未因 R5 改变 shape）：

```text
action  : float32[6] ∈ [-1,1]  → 每步 ≤1 mm / ≤0.25°
obs.state: tcp_pose[7], tcp_vel[6], joint_pos[8], hand_joints[6]
obs.images: head/wrist uint8[128,128,3]   # 真机图仍多为 Mock，待 R6
reward=0；terminated 占位 False；truncated ← max_steps/stale/安全/abort
close() → stop + clear_servo_params
```



### 0.4 对应现在能实现什么 / 还不能做什么

**已能实现**

1. 同一场景下 **反复** `env.reset()`，臂+腰回到标定悬停姿，再开连续控制；
2. 用 `scene_name` / 新 YAML **切换任务标定**，不必改 Env 代码；
3. 在 reset 成功后的 episode 内，用归一化 6D action 经 Env **唯一出口** 做 ServoL（R4 限幅 + episode 盒）；
4. Mock 路径用同一 scene 数值做离线对齐（`max_steps`、home TCP）；
5. Gate / 脚本验收可重复 reset（已 10/10）。

**尚不能（明确未做）**

一句话：**R5 完成后，Env 已具备「可重复开局的真机连续控制环」；还缺真实视觉与人工干预包装，才能采 demo / 跑 HIL-SERL。**

## 1. 目标与非目标（方案原文）



### 1.1 目标

1. 可重复自动 reset：手张开 → 腰 MoveJ → 左臂 MoveJ → 容差校验 → 场景确认 → 再开 ServoL episode；
2. 数值与策略放在 **场景 YAML**，换任务只复制改数，不改 Env 逻辑；
3. 失败/超时 `stop(+clear)`，**不进入 episode**；最多整段重试 1 次；
4. Gate：离线单测 + 真机连续 ≥10 次 reset。



### 1.2 非目标


| 不做                      | 归属           |
| ----------------------- | ------------ |
| 真实相机流水线                 | R6           |
| SpaceMouse Intervention | R7           |
| 桌面 XY 硬盒                | 本任务用头相机可见软策略 |




### 1.3 冻结决策


| 项                     | 值                                                  |
| --------------------- | -------------------------------------------------- |
| home ≡ task_reset_tcp | 是（同一姿态）                                            |
| 腰部                    | A：`auto_movej` + 容差                                |
| 工作区                   | `head_camera_visible_desktop`（无 xy_min/max）        |
| MoveL                 | 默认关（`do_movel_to_tcp: false`）                      |
| `max_steps`           | **1200**（场景覆盖契约默认 400）                             |
| 容差                    | 关节/腰 0.05 rad；手 0.1 rad；TCP 0.01 m / 5°            |
| 总超时                   | 60 s                                               |
| 确认                    | `R5_CONFIRM=YES` 才真运动；`RESET_SCENE_OK=YES` 或交互确认场景 |

## 2. 场景配置（可复制粘贴）

**运行时只读这一处**（容器内 / 与 `catkin_ws` 挂载一致）：

```text
catkin_ws/src/hilserl_wa2/configs/scenes/bottle_desktop.yaml   # 当前抓瓶任务
catkin_ws/src/hilserl_wa2/configs/scenes/_TEMPLATE.yaml        # 新任务模板
```

`scene_name="bottle_desktop"` **只是**文件名（不含 `.yaml`），用来选中上述目录里对应 YAML 的数值。  
Env **不会**读取仓库根目录其它 `configs/scenes/` 副本。

换任务：

```bash
cd /home/naviai/hilserl_orin/catkin_ws/src/hilserl_wa2/configs/scenes
cp _TEMPLATE.yaml my_new_task.yaml
# 只编辑「可粘贴数值区」：home_joints_left / home_joints_waist / task_reset_tcp / hand_reset
```

Env 用法：

```python
from hilserl_wa2.envs.wa2_env import WA2Env

env = WA2Env(
    fake_env=False,
    read_only=False,
    scene_name="bottle_desktop",  # → .../configs/scenes/bottle_desktop.yaml
    # 或：scene_path="/root/catkin_ws/src/hilserl_wa2/configs/scenes/my_new_task.yaml"
)
obs, info = env.reset()  # 失败会抛 RuntimeError，不进入 episode
```

## 3. reset 序列

```text
1) stop + clear_servo_params（结束上一 episode ServoL）
2) 手 → hand_reset（全 0 / release）
3) MoveJ 腰 → home_joints_waist（策略 A）
4) MoveJ 左臂 → home_joints_left
5) （可选）MoveL → task_reset_tcp
6) 校验臂/腰/手/TCP 容差 + is_singular=False
7) 场景人工确认（RESET_SCENE_OK 或 confirm_fn）
8) 新建 WA2ServoSession.start() → 允许 step()
```

任一步失败 → stop(+clear) → 可选整段重试 1 次 → 仍失败则 **不** `start()` ServoL。
