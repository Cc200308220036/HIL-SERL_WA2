## 1. 目标与非目标

### 1.1 目标

1. 建立 WA2 **真实双图像**进 `WA2Env.observation["images"]`：`head` + `wrist`；  
2. **不照搬** Franka 的序列号 / crop；现场盘点两路 topic 后冻结本机配置；

## 2. 架构与冻结语义

### 2.1 关键决策：订 ROS 图，不二次打开 USB

WA2 机载栈已发布（R6 双路均启用）：

```text
/zj_humanoid/sensor/realsense_head/color/image_raw   # head，R1 测 ~30 Hz，常见 720×1280
/zj_humanoid/sensor/left_wrist/image_raw             # wrist，现场已确认可调取（height/width/encoding 以实测为准）
```

上游 Franka 示例用 `pyrealsense2` 按序列号开管线。本项目 **采用 ROS Image 订阅**：

| 方式 | 选用 | 理由 |
|---|---|---|
| 订契约 topic + cv_bridge（head + wrist） | **是** | 与契约双键一致；不与机载驱动抢设备 |
| Env 内再 `rs.pipeline` 开同一序列号 | **否** | 易双开失败 / USB 带宽打满 |
| `rs-enumerate-devices` / `device_info` | **仅盘点** | 记录两路序列号唯一性，不启动第二管线 |

### 2.2 数据流

```text
机载相机驱动（头 + 左腕）
    │ sensor_msgs/Image × 2
    ▼
WA2ImageMonitor / WA2Cameras（R6）
    ├─ subscribe head  → decode RGB → crop → resize 128 → age
    ├─ subscribe wrist → decode RGB → crop → resize 128 → age
    └─ stale_fields: images/head, images/wrist（均启用）
    │
    ▼
WA2Env._get_obs()["images"]["head"|"wrist"]
    │
    ├─ 两路均 fresh → 正常 step
    └─ 任一路 age > image_max_age_s → truncated
         └─ 若 read_only=False：stop + clear
```

`fake_env=True`：继续 `MockCameras`，**不**订真 topic。

### 2.3 角色分配（抓瓶任务建议）

| 角色 | 相机 / 来源 | 说明 |
|---|---|---|
| **policy** | `head` + `wrist` 双键 | 均进 `obs["images"]`；训练侧 `image_keys` 后续在 R8 声明 |
| **classifier** | 默认优先 **腕** 近景 crop；或头图紧 ROI | 样例图存档；R12 再用 |
| 契约 | `wrist.enabled: true` | R6 实现时升契约小版本 |

两路 **各自** 维护 `policy_crop` /（可选）`classifier_crop`；坐标相对该路原始分辨率。

### 2.4 预处理冻结值（实现前按实测填全）

```text
# head
input_topic_head:  /zj_humanoid/sensor/realsense_head/color/image_raw
raw_shape_head:    (720, 1280, 3)     # 以实测为准
head_policy_crop:  null 或 [y0:y1, x0:x1]

# wrist（已启用）
input_topic_wrist: /zj_humanoid/sensor/left_wrist/image_raw
raw_shape_wrist:   (?, ?, 3)          # Step 0/1 实测后冻结
wrist_policy_crop: null 或 [y0:y1, x0:x1]
wrist_classifier_crop: 可与 policy 相同或更紧

# 共用
encoding:          源可为 rgb8/bgr8 → 适配器统一转 RGB；obs 永远 RGB
output_shape:      (128, 128, 3) uint8  # 每键
resize:            cv2.INTER_AREA
image_max_age_s:   0.2                 # 两路共用契约阈值；过紧可论证后放宽
target_fps_each:   ≥ 15（源 topic 建议 ≥25 Hz）
```

crop 约定：相对该相机 **原始分辨率** 的半开区间 `[y0:y1, x0:x1]`，先 crop 再 resize。

### 4.3 Step 2：头 + 腕抓原图与试 crop【容器】

```bash
python - <<'PY'
import os
import rospy
import numpy as np
import cv2
from sensor_msgs.msg import Image
from cv_bridge import CvBridge

OUT = "/root/catkin_ws/r6_samples"
os.makedirs(OUT, exist_ok=True)

TOPICS = {
    "head": "/zj_humanoid/sensor/realsense_head/color/image_raw",
    "wrist": "/zj_humanoid/sensor/left_wrist/image_raw",
}
# 相对各路原图试 crop；None=整图。例: (y0, y1, x0, x1)
CROPS = {
    "head": None,
    "wrist": None,
}

def to_rgb(msg, bridge):
    enc = (msg.encoding or "").lower()
    if "bgr8" in enc:
        bgr = bridge.imgmsg_to_cv2(msg, desired_encoding="bgr8")
        return cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB), msg.encoding
    if enc in ("rgb8", "") or "rgb8" in enc:
        return bridge.imgmsg_to_cv2(msg, desired_encoding="rgb8"), msg.encoding
    rgb = bridge.imgmsg_to_cv2(msg, desired_encoding="passthrough")
    if rgb.ndim != 3 or rgb.shape[2] != 3:
        raise RuntimeError(f"bad encoding={msg.encoding} shape={getattr(rgb,'shape',None)}")
    return rgb, msg.encoding

rospy.init_node("r6_grab_dual", anonymous=True)
bridge = CvBridge()
for name, topic in TOPICS.items():
    msg = rospy.wait_for_message(topic, Image, timeout=5.0)
    rgb, enc = to_rgb(msg, bridge)
    assert rgb.dtype == np.uint8 and rgb.shape[2] == 3
    print(name, "shape", rgb.shape, "encoding", enc)
    cv2.imwrite(f"{OUT}/{name}_raw_bgr_for_view.png", cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR))
    crop = CROPS[name]
    if crop is None:
        cropped = rgb
    else:
        y0, y1, x0, x1 = crop
        cropped = rgb[y0:y1, x0:x1]
    out128 = cv2.resize(cropped, (128, 128), interpolation=cv2.INTER_AREA)
    cv2.imwrite(f"{OUT}/{name}_policy_128.png", cv2.cvtColor(out128, cv2.COLOR_RGB2BGR))
    cv2.imwrite(f"{OUT}/{name}_crop_fullres_bgr.png", cv2.cvtColor(cropped, cv2.COLOR_RGB2BGR))
    # classifier：腕近景可先与 wrist policy 相同，或另设 CROPS 后再跑一遍
    if name == "wrist":
        cv2.imwrite(f"{OUT}/classifier_128.png", cv2.cvtColor(out128, cv2.COLOR_RGB2BGR))

print("wrote dual samples to", OUT)
print("FREEZE_CROPS=", CROPS)
PY
```

import time
