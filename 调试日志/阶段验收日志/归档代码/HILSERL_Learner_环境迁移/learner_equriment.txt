五、Learner 专用依赖锁定与安装
--------------------------------------
`requirements/hil-learner.lock.txt` 是从隔离后的 hil-learner 环境生成的
Linux x86_64 专用锁定文件，共固定 95 个 pip 包。它包含 JAX 四件套、
TensorFlow 栈、OpenCV，以及 JAX GPU 所需的 11 个 NVIDIA CUDA 12 wheel。

该 lock 不包含用户 site-packages 中的 ROS2、diffusers、datasets 等无关包，
也不包含必须从工程本地安装的 Agentlace 和 serl_launcher。

安装时使用 --no-deps，避免 pip resolver 重新选择 jaxlib、CUDA runtime、
Gymnasium 或 SciPy 版本。lock 已列出完整传递依赖闭包。

建议命令（得到许可且环境创建后才执行）：

  cd /home/cyw/orin_hilserl/HILSERL_Learner
  source /home/cyw/anaconda3/etc/profile.d/conda.sh
  conda activate hil-learner
  export PYTHONNOUSERSITE=1

  python -m pip install --no-deps \
    -r requirements/hil-learner.lock.txt

不再使用 `requirements/actor-requirements.txt` 或
`requirements/orin-hil-actor.lock.txt` 创建空白 Learner 环境；二者都是
Orin Actor 基线，后者尤其没有覆盖 TensorFlow/Matplotlib 等完整 import 闭包。

八、GPU 运行环境变量
----------------------
R10 正式 Gate 不设置 `JAX_PLATFORMS=cpu`。若 shell 中残留该变量，必须清除：

  unset JAX_PLATFORMS

建议：

  export CUDA_ROOT=/usr/local/cuda
  export XLA_FLAGS=--xla_gpu_autotune_level=0
  export XLA_PYTHON_CLIENT_PREALLOCATE=false
  export XLA_PYTHON_CLIENT_MEM_FRACTION=0.3

  export PYTHONPATH=/home/cyw/orin_hilserl/HILSERL_Learner/src:\
/home/cyw/orin_hilserl/HILSERL_Learner/src/hil-serl-main/examples:\
/home/cyw/orin_hilserl/HILSERL_Learner/src/hil-serl-main/serl_launcher:${PYTHONPATH:-}

`CUDA_ROOT=/usr/local/cuda` 也避免某些 JAX 0.4.35 组合在检查
`nvidia.cuda_nvcc.__file__` 时遇到 namespace package 路径为 None 的问题。

同一验收进程按顺序：先 import jax，再 import tensorflow。

十一、网络（环境/Env/GPU Gate 通过后才配置）
--------------------------------------------------
Learner 是 Agentlace Server：

  TCP 5588：transition / request
  TCP 5589：params broadcast

要求：

  笔记本使用确认过的局域网 IPv4。
  Learner 先启，Orin Actor 后启。
  防火墙仅允许 Orin IPv4/32 访问 5588/5589。
  不允许 0.0.0.0/0，不做路由器公网端口转发。

不在 Conda 环境安装尚未验收时就开放端口。


十二、R7000P 资源边界
----------------------
R10 主 Gate：

  1020 条 actor_env（其中 1000 条非干预）
  20 条 actor_env_intvn
  一个连续干预段
  小型有限 DataStore

该规模可在 16 GB 系统内存上执行。

R13 不得直接使用 YAML 当前：

  batch_size=256
  replay_buffer_capacity=200000

双 128x128 RGB 观测下，20 万 transition 的原始图像数据已可达数十 GB，
超出 16 GB 系统内存的安全边界。R13 必须另行压测 batch、capacity、
MemoryEfficientReplayBuffer、GPU 显存和 checkpoint，不在 R10 中修改 Env/space 契约。
