## 1. 目标与非目标

### 1.1 目标

在 **不发送任何机器人动作** 的前提下：

1. 用真实 WA2 ROS 状态填充 `observation["state"]`；
2. 抽出独立的 `WA2StateMonitor`（订阅与 Env 解耦）；
3. 用 monotonic 时钟做新鲜度 / stale 门控；
4. `step()` 保持 Gymnasium API，但 **明确只读、不发 ServoL**；
5. 图像仍用 R2 Mock（`head` 图案/`wrist` 零图）；真实相机属 **R6**。

### 1.2 非目标

| 不做 | 归属 |

| 真机 reset/home 运动 | R5 |
| RealSense 解码 / resize | R6 |
| SpaceMouse Intervention | R7 |
| 改契约 space 键名或 shape | 需重回 R1 |

## 2. 架构与冻结语义

### 2.1 数据流

```text
ROS topics (只订阅)
  ├─ /zj_humanoid/upperlimb/tcp_pose/left_arm
  ├─ /zj_humanoid/upperlimb/tcp_speed/dual_arm
  ├─ /zj_humanoid/upperlimb/joint_states
  ├─ /zj_humanoid/hand/joint_states
  └─ /zj_humanoid/upperlimb/uplimb_state
        │
        ▼
WA2StateMonitor  ──get_state()/ages()/info()──►  WA2Env(fake_env=False, read_only=True)
        │                                            │
        │                                            ├─ images ← MockCameras（R3 不变）
        │                                            ├─ step(action)：校验 action，不发运动
        │                                            └─ stale → truncated + info["stale"]=True
        ▼
禁止：servol / movel / movej / hand switch / stop（除人工应急）
```

### 2.2 `step` 只读语义（冻结）

| 行为 | R3 规定 |
|---|---|
| 校验 action shape / NaN | 是（与 R2 相同） |
| clip 到 [-1,1] | 是（可写入 info，便于对照） |
| 发布 ServoL / 改 MockRobot 姿态 | **否** |
| 刷新 observation | **是**（来自 StateMonitor） |
| reward | `0.0` |
| terminated | 恒 `False`（除非测试钩子） |
| truncated | `max_steps` **或** 状态 stale / ROS shutdown |
| info | `read_only=True`, `fake_env=False`, ages, singular, cmd_* |

非零 action **不得**引起机器人运动；验收以“机械臂保持静止”为准。

### 2.3 新鲜度（契约）

```text
state_max_age_s = 0.2
```

任一关键左臂状态超龄 → `truncated=True`，`info["stale"]=True`，`info["stale_fields"]=[...]`。  
**不得**因 `wrist` 图像未启动而 truncated（图像仍 Mock）。

## 4. 实现规格

### 4.1 `WA2StateMonitor`

```text
类：WA2StateMonitor
职责：只订阅、缓存、计龄、拷贝返回；不发布任何命令

__init__(arm="left", state_max_age_s=0.2, joint_names=...)
start() / stop() / wait_ready(timeout_s)
get_state() -> dict[str, np.ndarray]   # 深拷贝
get_ages() -> dict[str, float|None]    # monotonic 年龄
get_info() -> is_singular, cmd_num, cmd_name, iddp_status, ages...
is_fresh() -> bool
stale_fields() -> list[str]
inject_stale_for_test(...)             # 单测/Gate 钩子
```

要求：

- 时间戳用 `time.monotonic()`，不用 wall clock 做年龄；
- `get_state()` **必须返回副本**；
- 左臂关节按契约 8 名切片；手部按左手 6 名；
- `tcp_vel` 取 `TcpSpeed.left_arm`；
- `tcp_pose` 四元数 **xyzw**，与 R1/R2 一致；
- ROS shutdown 时 `wait_ready`/读循环可退出，不永久 block。

允许内部复用 `NaviController` **只读 API**（`get_tcp_rt` / `get_joints` / `get_tcp_age` 等），但：

- R3 代码路径 **不得**调用 `servol` / `movel` / `movej` / `stop` / hand；
- 更推荐独立 subscriber，避免误用控制 API。

### 4.2 `WA2Env` 扩展

```python
WA2Env(
  fake_env=False,
  read_only=True,          # R3 强制 True；False 留待 R4
  contract_path=...,
  seed=...,
)
```

规则：

| 模式 | 后端 | 动作 |
|---|---|---|
| `fake_env=True` | MockRobot + MockCameras | R2 行为（回归保留） |
| `fake_env=False, read_only=True` | StateMonitor + MockCameras | 校验 action，不运动 |
| `fake_env=False, read_only=False` | R4 | 本阶段 `NotImplementedError` / 禁止 |

`close()`：停止 Monitor；可重复调用；**不**自动 `stop` service（只读阶段无会话），但 info 可保留 `would_stop_on_close` 语义说明。

### 4.3 必测场景

| ID | 场景 | 期望 |
|---|---|---|
| T01 | Monitor 返回 shape | 7/6/8/6 |
| T02 | get_state 副本 | 修改返回值不污染缓存 |
| T03 | ages monotonic | 停更后 age 增大 |
| T04 | stale 超 0.2 s | `is_fresh()==False` |
| T05 | 只读 Env reset/step | obs in space；`read_only` in info |
| T06 | 非零 action | 机器人逻辑上不调用发布；单测断言无 publish |
| T07 | stale step | `truncated=True` |
| T08 | fake_env=True 回归 | R2 全测仍 PASS |
| T09 | 错误臂字段 | 不出现右臂关节名混入左臂 |

## 6. 验收标准（Gate R3）

**全部满足方可进入 R4。**

### 6.1 安全与只读

- [ ] 验收全程 **机器人保持静止**（TCP 漂移阈值建议 &lt; 5 mm，现场噪声可记入日志）
- [ ] 代码路径与日志证明 **未**调用 ServoL / Move* / 手部 service
- [ ] `info["read_only"] is True`，`info["fake_env"] is False`
- [ ] 未与遥操脚本并行

### 6.2 观测与空间

- [ ] `observation` 每个字段属于 `observation_space`
- [ ] 无 NaN/Inf；shape 固定为契约 7/6/8/6 与图像 128×128×3
- [ ] `info` 含 `is_singular`、`cmd_num`、`state_age`（或分字段 ages）
- [ ] 左右臂不串侧（左臂关节名 / left TCP）

### 6.3 新鲜度与故障

- [ ] 关键 topic 超 `state_max_age_s=0.2` 后，在 watchdog 内 `truncated` + `stale`
- [ ] 恢复策略与契约一致：stale 清除且数据新鲜后可继续 step（或要求显式 reset——须在实现/日志写明一种）
- [ ] ROS shutdown / Monitor stop 后调用可结束，不永久阻塞

### 6.4 浸泡与回归

- [ ] 连续读取 **≥10 分钟** 无崩溃、无 shape 变化、无异常内存持续增长
- [ ] `python -m unittest discover -s src/hilserl_wa2/tests/unit -v` **全部 PASS**
- [ ] `verify_r2_mock_env.py` 仍为 **R2 GATE: PASS**
- [ ] `verify_r3_readonly_env.py` 输出 **R3 GATE: PASS**

## 8. 风险与注意

1. **奇异标志**：静止采样时 `is_singular=True` 可能出现；R3 只读入 info，不因此自动运动；R4 发力前再门控。
