## 4. R1 目标与非目标

### 4.1 目标

在不发送动作的前提下，冻结一份可评审、可复现的 **WA2Env 契约**，使：

1. Actor 与 Learner 仅凭契约就能构造相同 `observation_space` / `action_space`；
2. R2 Mock Env、R3 只读 Env、R4 执行器都能按同一语义实现；
3. 双相机观测键名、消息来源、缺失策略在契约中写死（手腕相机当前未启动也要写清）。

### 4.2 非目标（明确不做）

- 不实现 `WA2Env.step()` 真机执行（R4）；
- 不实现 Mock Env / 单元测试（R2）；
- 不实现 Intervention Wrapper（R7）；
- 不完成 RealSense 设备级稳定性验收（R6；R1 只冻结 topic/键名/缺失策略）；
- 不定最终任务 reward classifier（R12）。

## 5. 已冻结的架构决策（R1 必须写入契约）

### 5.1 控制链路

```text
WA2Env → NaviController / ROS topic·service → WA2
```

不引入 Franka HTTP Robot Server。

### 5.2 连续控制入口（契约记录，R1 不调用）

```text
/zj_humanoid/upperlimb/set_servo_params
/zj_humanoid/upperlimb/servol/{left,right}_arm
/zj_humanoid/upperlimb/stop
/zj_humanoid/upperlimb/clear_servo_params
```

唯一动作发布者原则（从 R4 起强制）：

```text
SpaceMouse 只产生 Env action
→ Wrapper 决定是否覆盖 policy action
→ WA2Env 是唯一机器人动作出口
```

### 5.3 第一阶段范围

| 项 | R1 冻结值 |
|---|---|
| 手臂 | **仅左臂** |
| action 维度 | **6D**（灵巧手暂不进策略动作） |
| 灵巧手 | episode 外预抓握 / 人工控制；7D 为后续阶段 |
| 控制频率 | 50 Hz / 20 ms |
| 坐标系 | 必须在契约中二选一并写死：`tool` 或 `base`（建议先对齐现有遥操：以当前已验收语义为准，评审时确认） |

### 5.4 双相机观测（当前实际情况）

| 相机键名（契约） | ROS topic | 当前状态 | R1 要求 |
|---|---|---|---|
| `head` | `/zj_humanoid/sensor/realsense_head/color/image_raw` | **应可用 / 需盘点确认** | 记录类型、shape、hz、编码、时间戳；采 ≥10 帧样本 |
| `wrist` | `/zj_humanoid/sensor/left_wrist/image_raw`（候选） | **按 hz 判定；未发布则 not_started** | 契约中可 `enabled: false`；仍预留 obs 键与 shape |

说明：

- 第一版 `observation["images"]` **固定两个键**：`head`、`wrist`，避免后续改 space 破坏 Learner / buffer；
- 手腕未发布时：真实 Env 的缺失策略见 §7 Step 6；`fake_env` 用同 shape 零图或样本图；
- 不得照搬 Franka 示例中的 RealSense 序列号 / crop；
- 设备级 FPS、丢帧、USB 带宽验收归属 **R6**，R1 只完成 topic 级盘点与契约占位；
- **所有可复制粘贴命令见 §3**。

### Step 4：冻结 WA2Env 契约正文（60～90 min）

- 命令（落盘骨架）：§3.6

编写 `docs/WA2Env接口契约.md` + `configs/experiments/wa2_env_contract.yaml`。  
内容必须覆盖下列小节（可直接作为契约目录）。

#### Action space（第一版 6D）

```text
action.shape = (6,)
action.dtype = float32
action.low/high = -1 .. 1
语义 = [dx, dy, dz, droll, dpitch, dyaw]
```

物理缩放（首个真机 Gate 候选，写入 YAML，R4 前可微调但需改版本号）：

```text
max_pos_delta = 0.0005 ~ 0.001 m/step   # 0.5～1.0 mm
max_rot_delta = 0.1 ~ 0.25 deg/step
control_dt = 0.02 s
frame = tool | base   # 二选一，评审锁定
```

7D 扩展只作为附录：

```text
[dx, dy, dz, droll, dpitch, dyaw, hand]
hand 语义：连续目标 / 三态命令 / 边沿事件 —— 必须显式选择，禁止沿用按钮 toggle 隐式语义
```

#### Observation space

```text
observation = {
  "state": {
    "tcp_pose":    float32[7],   # xyz + quat xyzw
    "tcp_vel":     float32[6],
    "joint_pos":   float32[8],   # 左臂
    "hand_joints": float32[6]    # 左臂对应灵巧手
  },
  "images": {
    "head":  uint8[H, W, 3],
    "wrist": uint8[H, W, 3]      # 未启动时按 missing_policy 填充
  }
}
```

以下字段进 `info` / 安全门控，**默认不进策略观测**：

```text
is_singular, state_age, image_age, cmd_num, error/estop flags, intervene flags
```

#### Step / Reset / Close 语义

```text
reset() -> observation, info
step(action) -> observation, reward, terminated, truncated, info
close() -> stop + clear_servo_params + 释放订阅/相机资源
```

必须写清：

| 符号 | 初始定义（R1 候选） |
|---|---|
| `reward` | 恒 0 或外部占位；**不得**宣称已接 classifier |
| `terminated` | 任务成功或确定失败（任务未定时可先恒 False） |
| `truncated` | max_steps / 状态超时 / 图像超时 / 安全边界 / 人工中止 |
| `reset/home` | 选定**可验证**候选流程 + 人工确认点（见 Step 5）；禁止“只清内部计数” |
| 异常路径 | 先 stop，再抛异常或返回 truncated |

#### 安全与生命周期

契约中固定：

1. 唯一 ServoL 发布者 = WA2Env（R4 起）；
2. stale / singular 时不得发新动作；
3. `close()` 可重复调用且幂等；
4. Actor/Env 异常退出必须 stop/clear；
5. 网络断开不得重复旧动作（R9/R10 细化，R1 先写原则）。

#### YAML 最小骨架（实现时填实测值）

```yaml
version: "0.1.0"
arm: left
action:
  dim: 6
  dtype: float32
  low: -1.0
  high: 1.0
  frame: TBD_tool_or_base
  max_pos_delta_m: 0.001
  max_rot_delta_deg: 0.25
  control_hz: 50
observation:
  state:
    tcp_pose: {shape: [7], dtype: float32, unit: "m+quat_xyzw", topic: "/zj_humanoid/upperlimb/tcp_pose/left_arm"}
    tcp_vel: {shape: [6], dtype: float32, topic: "/zj_humanoid/upperlimb/tcp_speed/dual_arm"}
    joint_pos: {shape: [8], dtype: float32, topic: "/zj_humanoid/upperlimb/joint_states"}
    hand_joints: {shape: [6], dtype: float32, topic: "/zj_humanoid/hand/joint_states"}
  images:
    head:
      topic: "/zj_humanoid/sensor/realsense_head/color/image_raw"
      enabled: true
      shape: [TBD_H, TBD_W, 3]
      dtype: uint8
    wrist:
      topic: "/zj_humanoid/sensor/left_wrist/image_raw"
      enabled: false
      status: not_started
      shape: [TBD_H, TBD_W, 3]
      dtype: uint8
      missing_policy: zero_image
freshness:
  state_max_age_s: 0.2
  image_max_age_s: 0.2
episode:
  max_steps: TBD
  reward: constant_zero
  terminated: task_placeholder
  truncated: [max_steps, stale_state, stale_image, safety, manual_abort]
reset:
  strategy: TBD_candidate   # Step 5 选定
  requires_human_confirm: true
control:
  backend: servol
  topics:
    set_servo_params: "/zj_humanoid/upperlimb/set_servo_params"
    servol: "/zj_humanoid/upperlimb/servol/left_arm"
    stop: "/zj_humanoid/upperlimb/stop"
    clear: "/zj_humanoid/upperlimb/clear_servo_params"
  sole_action_publisher: WA2Env
fake_env:
  touches_ros: false
  touches_camera: false
  image_fill: zeros
```

### Step 5：reset/home 候选方案选型（30～45 min，可含人工评审）

R1 **不执行** reset，但必须消掉契约里的 `TBD`。建议在文档中列出并选定其一：

| 候选 | 描述 | 优点 | 风险 |
|---|---|---|---|
| A. 固定关节 home + MoveJ | 记录一组安全关节角，reset 同步 MoveJ | 可重复性好 | 需人工标定安全角；点到点较慢 |
| B. 固定 TCP + MoveL | 记录安全 TCP，reset 用 MoveL | 与任务位姿直观 | 奇异/障碍路径需验证 |
| C. 记录“episode 起始姿态”快照 | 每次实验前人工摆位，Env 只校验容差 | R1/R2 最快落地 | 不可全自动；不适合无人训练 |
| D. 两段式 | 先 MoveJ 到粗 home，再 MoveL 到任务位 | 兼得安全与精度 | 实现与验收更长 |

**R1 推荐默认：** 先冻结 **C（人工摆位 + 容差校验）** 作为 Mock/只读阶段可用方案，同时在附录保留 **A** 作为 R5 自动化目标。评审时必须勾选：

- [ ] 选定主方案 + 容差（关节/TCP）；
- [ ] 写出人工确认点（急停位、线缆、双臂间隙）；
- [ ] 写明 reset 超时与失败 → stop，且不进入 episode。

### Step 6：图像缺失与 fake_env 策略写死（15～30 min）

#### 6.1 真实 Env（`fake_env=False`）

| 情况 | 行为 |
|---|---|
| `head` 正常 | 解码 → resize/crop（参数 R6 定）→ `uint8[H,W,3]` |

```text
hold_placeholder_png  # 固定样本图路径
```

**R1 默认：`zero_image`。**

硬要求（与总览 §17.2 对齐，R1 先写入契约）：

- `images/head` 与 `images/wrist` 均为同 shape 零图或缓存样本图；
