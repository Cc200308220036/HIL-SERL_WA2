### 3.6 Step 5：fake_env 硬件隔离检查【容器】

证明构造路径不碰 ROS/相机：

```bash
python - <<'PY'
import sys
import builtins

blocked = {"rospy", "cv2", "cv_bridge", "sensor_msgs", "upperlimb", "naviai_controller"}
real_import = builtins.__import__

def guarded_import(name, *args, **kwargs):
    root = name.split(".")[0]
    if root in blocked:
        raise ImportError(f"R2 fake_env must not import {name}")
    return real_import(name, *args, **kwargs)

builtins.__import__ = guarded_import
try:
    # 清掉可能已加载的模块名（干净解释器下通常为空）
    for m in list(sys.modules):
        if m.split(".")[0] in blocked:
            del sys.modules[m]
    from envs.wa2_env import WA2Env
    env = WA2Env(fake_env=True, seed=1)
    obs, info = env.reset(seed=1)
    obs, r, te, tr, info = env.step(env.action_space.sample())
    env.close()
    print("FAKE_ENV_ISOLATION: PASS")
finally:
    builtins.__import__ = real_import
PY
```

### 3.7 Step 6：seed 可复现【容器】

```bash
python - <<'PY'
import numpy as np
from envs.wa2_env import WA2Env

def rollout(seed):
    env = WA2Env(fake_env=True, seed=seed)
    obs0, _ = env.reset(seed=seed)
    outs = [obs0["state"]["tcp_pose"].copy()]
    actions = []
    rng = np.random.default_rng(seed)
    for _ in range(20):
        a = rng.uniform(-1, 1, size=(6,)).astype(np.float32)
        actions.append(a)
        obs, *_ = env.step(a)
        outs.append(obs["state"]["tcp_pose"].copy())
    env.close()
    return actions, outs

a1, o1 = rollout(123)
a2, o2 = rollout(123)
assert all(np.allclose(x, y) for x, y in zip(a1, a2))
assert all(np.allclose(x, y) for x, y in zip(o1, o2))
print("SEED_REPRO: PASS")
PY
```

## 4. 实现规格（编码时对照）

### 4.1 建议类与职责

```text
WA2EnvContract (contracts.py)
  - from_yaml(path) -> 常量/spaces
  - build_observation_space() / build_action_space()

MockRobot (mock_robot.py)
  - reset(home) / apply_action(action6) / get_state_dict()
  - 内部维护 tcp_pose(7)、tcp_vel(6)、joint_pos(8)、hand_joints(6)
  - 平移：base 增量；旋转：tool 右乘；步长按契约限幅
  - 禁止 import rospy

MockCameras (mock_cameras.py)
  - get_images() -> {"head": uint8[128,128,3], "wrist": uint8[128,128,3]}
  - wrist 始终零图（enabled=false）
  - head：zeros 或 seed 可复现图案；禁止打开设备

WA2Env (wa2_env.py)
  - __init__(fake_env=True, contract_path=..., seed=None)
  - fake_env=True 时仅走 Mock*（R2 默认且验收只用此路径）
  - reset / step / close 符合 Gymnasium 5-tuple API
```

### 4.2 `step` 语义

```text
action ← clip 到 [-1,1]
拒绝 NaN/Inf/错误 shape（raise ValueError，不推进内部时钟也可，但须单测覆盖）
物理增量 ← action * scale，且 |Δp|≤1mm、|Δθ|≤0.25°
MockRobot 更新状态
obs ← state + images
reward ← 0.0
terminated ← False（除非测试注入）
truncated ← (step_count >= max_steps) 或安全注入
info ← {is_singular, state_age, image_age, cmd_num, ...} 可用 Mock 常量
```

### 4.3 `reset`（Mock）

- 不要求人工确认（真机策略属 R5；Mock 直接回到固定 home）；
- home 可用契约样本附近的常量姿态（例如单位四元数 + 固定 xyz/关节）；
- 返回 `(obs, info)`，`obs in observation_space`。

### 4.4 `close`

- Mock：只做标志位/释放引用；
- **可重复调用**不抛异常；
- 不调用真实 `stop` service（无 ROS）；可在 info/日志中记录 “would_stop”。

### 4.5 与既有 `PoseIntegrator` 的关系

允许复用 `interventions/pose_integrator.py` 做姿态积分，但：

- 不得在 `fake_env` 路径 import rospy；
- 限幅数字必须来自契约 YAML，不能写死另一套；
- 若复用导致混合平移+旋转策略与 Env 不一致，优先在 MockRobot 内实现与契约一致的积分。

## 7. 验收标准（Gate R2）

**全部勾选方可进入 R3。**

### 7.1 功能与 API

- [ ] `WA2Env(fake_env=True)` 可构造，无需 ROS Master / 相机 / 机器人
- [ ] `gymnasium.utils.env_checker.check_env(env, skip_render_check=True)` **通过**
- [ ] 连续 **1000** 个随机 action **无异常**，obs 均在 space 内
- [ ] `reset` / `step` / `close` 符合 Gymnasium 新 API（5-tuple + reset info）
- [ ] `close()` 连续调用 ≥2 次不抛异常

### 7.2 与 R1 契约一致

- [ ] `action_space.shape == (6,)`，dtype float32，范围 [-1,1]
- [ ] `observation["state"]` 含且仅含契约四态键，shape 为 7/6/8/6
- [ ] `observation["images"]` 含 `head` 与 `wrist`，均为 `uint8 (128,128,3)`
- [ ] 包内契约与仓库根契约 **SHA256 一致**（或明示同步流程）
- [ ] 单步物理增量不超过 `0.001 m` / `0.25°`
- [ ] `max_steps=400` 触发 `truncated`
- [ ] `reward` 为 0 占位；不得假装已接 classifier

### 7.3 隔离与回归

- [ ] fake_env 构造/step **不 import** `rospy` / `cv_bridge` / `naviai_controller` / `upperlimb`
- [ ] 固定 seed 轨迹可复现
- [ ] `python -m unittest discover -s src/hilserl_wa2/tests/unit -v` **全部 PASS**（含原 SpaceMouse 测试）

## 9. 风险与注意

1. **勿改 observation 键名/shape** 来“图省事”；要改必须升契约 version 并重回 R1 评审。  
2. **configs/ 不在容器默认挂载**：始终以包内 `hilserl_wa2/configs/wa2_env_contract.yaml` 为准运行。  
3. **不要在 R2 引入 rospy 单例**：会破坏 Learner `fake_env` 隔离。  
4. **手腕未启动** 不是缺陷：Mock 必须零图且不 truncated。  
5. `check_env` 对 info/无限空间较严：`tcp_pose` 等可用合理 `Box` 低高界（按物理范围设，如位置 ±2 m、四元数 ±1）。
