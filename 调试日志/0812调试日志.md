## 6. R7：SpaceMouse Intervention（进 Env）

### 6.1 做了什么

把 SpaceMouse 从「teleop 脚本直接 ServoL」接到 **Env 唯一出口**：

```text
/spacenav/joy → JoyWatchdog → SpaceMouseInputProcessor
  → WA2SpacemouseIntervention
      ├─ deadman+新鲜+有效轴 → info["intervene_action"] = 实际 step 动作
      └─ 否则 passthrough policy
  → WA2Env.step → ServoL
```

约束：无 Franka HID；Wrapper **不**直接调 ServoL/手；与 `spacemouse_wa2_teleop` **互斥**；复用 0810 标定映射（`spacemouse_input.py`）。

## 7. SpaceMouse 工程化改进（配置 + 启动）

### 7.1 动机

- 正式实验不宜长期依赖「三终端手搓 + 超长 `_param:=`」；  
- 手感/轴符号/限幅应与 Intervention、排障 teleop **同源**；  
- Joy 守护进程（`spacenavd` + `spacenav_node`）需可一键拉起。

### 7.2 形态

```text
configs/spacemouse/default.yaml
        │
        ├─→ load_spacemouse_config() / WA2SpacemouseIntervention   （训练/示教）
        ├─→ run_spacemouse_teleop_from_yaml.py                     （排障直连 ServoL）
        └─→ start_spacemouse_joy.sh                                （起输入链）
```

仍强调：**teleop 与 Env Intervention 不可同开**（双 ServoL 发布者）。

### 7.3 问题与修复

首次 `start_spacemouse_joy.sh` 在 Joy 已约 30 Hz 时误报 `WARN`：根因是 `set -o pipefail` 下 `rostopic hz | head` 被 SIGPIPE。已改为「写临时文件 + 检测 `average rate`」，复验 **`SPACEMOUSE_JOY: OK`**。

### 7.4 新增 / 相关文件（一句话）

| 路径 | 一句话说明 |
|---|---|
| `configs/spacemouse/default.yaml` | SpaceMouse 统一运行配置（joy/按键/映射/intervention/teleop/launch） |
| `interventions/spacemouse_config.py` | 加载 YAML → `SpaceMouseRuntimeConfig`，供框架与脚本调用 |
| `scripts/start_spacemouse_joy.sh` | 按配置确保 spacenavd + spacenav_node 并检查 Joy Hz |
| `scripts/run_spacemouse_teleop_from_yaml.py` | 用同一 YAML 启动排障遥操（`--dry-run` 可预览参数） |
| `tests/unit/test_spacemouse_config.py` | YAML 加载与 Wrapper 读配置单测 |
| （复用）`interventions/spacemouse_input.py` | 0810 标定的轴映射/意图/滤波核心（Intervention 与 teleop 共用） |
| （复用）`interventions/spacemouse_wa2_teleop.py` | 直连 ServoL 的诊断遥操实现（现可由 YAML 启动器驱动） |

### 7.5 推荐用法（摘要）

```bash
# Joy 链
bash /root/catkin_ws/src/hilserl_wa2/scripts/start_spacemouse_joy.sh

# 排障遥操（勿与 Env 同开）
python .../run_spacemouse_teleop_from_yaml.py

# 训练/示教侧
# WA2SpacemouseIntervention(WA2Env(...))  # 默认读 default.yaml
```

## 9. 关键问题与经验

1. **`spacenav_node` 在 `/root/catkin_ws`**：必须 `source /root/catkin_ws/devel/setup.bash`，仅 source `/opt/ros` 会找不到包。  
2. **SpaceMouse 未插入时 Joy 无数据**：先接设备再起链；验收中曾因此卡住 live Gate。  
3. **互斥**：指南三终端遥操适合排障；R7/训练必须停 teleop。  
4. **PYTHONPATH**：容器内需 `export PYTHONPATH=/root/catkin_ws/src:$PYTHONPATH`，否则 `No module named hilserl_wa2`。  
5. **脚本健康检查**：长驻命令勿与 `head`+`pipefail` 直接管道判断成功。
