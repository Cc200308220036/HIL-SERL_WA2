## 1. 目标与非目标



### 1.1 目标

1. 在 Orin 同一容器内建立有限步的本地闭环：
  `WA2 Env → Actor transition → Agentlace TrainerClient → dummy TrainerServer`；
2. 先用 `fake_env` 生成至少 100 条 schema 一致的 transition，不访问任何硬件；
3. 验证 SAC actor 能对 R8 观测完成推理，但该未训练策略只允许在 fake/read-only 模式运行；
4. 将 transition 实际上传到 dummy Server 的 `actor_env`，以 Server 计数作为成功权威证据；
5. 通过合成 Joy 和真 SpaceMouse 验证 `intervene_action` 是实际执行 action，干预 transition 同时进入 `actor_env_intvn`；
6. 冻结 `terminated` / `truncated` 对 `dones` / `masks` 的 transition 语义；
7. 验证 dummy Server 广播与 Actor 模型结构相容的参数，Actor callback 至少成功替换一次参数；
8. 实现周期上传、上传确认、网络/Server watchdog 和 fail-closed；
9. Server 中断、Actor 异常、`Ctrl+C`、Env stale/truncated 均必须执行 `env.close()`，真机时落到 ServoL `stop + clear`；
10. transition dump 能从磁盘重新加载，数量、schema、shape、dtype 和 hash 一致；
11. 最后用零 policy + SpaceMouse 在真机小范围内验证实际 WA2 transition 数据链。



### 1.2 非目标


| 不做                            | 归属 / 原因                                       |
| ----------------------------- | --------------------------------------------- |
| Orin ↔ 外部笔记本通信                | R10；R9 Client 仅连接 `127.0.0.1`，5588/5589 不对外放行 |
| Learner 梯度更新 / RLPD 训练        | R10/R13                                       |
| 未训练 SAC policy 真机运动           | **禁止**；行为不可预测                                 |
| 大幅真机动作或完整抓瓶任务                 | R9 只验数据闭环，不追求任务成功                             |
| 正式 demo 采集                    | R11                                           |
| Reward Classifier / 非零 reward | R12；R9 保持 `reward=0`                          |
| W&B 在线日志                      | R9 强制 `--debug` 或专用 Gate，不依赖外网                |
| 直接运行无限循环的正式 Actor             | R9 先使用可限步、可注入故障的 Gate                         |
| 修改 Env action/observation 契约  | 不在 R9 范围                                      |

## 2. 架构与冻结语义



### 2.1 R9 数据流

```text
                         Orin / hilserl / hil-actor

 policy_action[6] ──────────┐
                              │
 SpaceMouse / synthetic Joy ───┤
                              ▼
                  WA2SpacemouseIntervention
                  │ no intervention: policy action
                  └ intervention: info["intervene_action"]
                              │
                              ▼
                         WA2Env.step
                              │
                              ▼
                    build_actor_transition
                    ├ actions = actual executed action
                    ├ terminated/truncated semantics
                    └ schema/finite validation
                              │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
            actor_env queue                    actor_env_intvn queue
            （所有 transition）                 （仅干预 transition）
                    └──────────────────┬─────────────────┘
                                      ▼
                         TrainerClient.update(confirm)
                          TCP 5588 / 127.0.0.1
                                      ▼
                         dummy TrainerServer
                         ├ actor_env server store
                         └ actor_env_intvn server store

 dummy Server ── publish compatible agent params ── TCP 5589 ──▶ Actor callback
```



### 2.2 Action 与控制权（强制）


| 阶段       | policy action            | 人工干预                     | 机器人运动        |
| -------- | ------------------------ | ------------------------ | ------------ |
| fake     | SAC / zero / scripted 均可 | 合成 Joy                   | 否            |
| readonly | SAC 可推理，但 Env 忽略动作       | 真 SpaceMouse             | 否            |
| live     | **强制 zero policy**       | 真 SpaceMouse deadman 后覆盖 | 是，仅干预产生小范围运动 |


真机链路中的物理动作出口仍唯一：

```text
SpaceMouse 或 zero policy
  → WA2SpacemouseIntervention
  → WA2Env
  → WA2ServoSession
  → ServoL
```

`spacemouse_wa2_teleop.py` / `run_spacemouse_teleop_from_yaml.py` 与 R9 Actor **严格互斥**。

### 2.3 Transition schema

```python
transition = {
    "observations": obs,
    "actions": executed_action,       # 干预时必须是 intervene_action
    "next_observations": next_obs,
    "rewards": np.float32(reward),
    "masks": np.float32(mask),
    "dones": np.bool_(done),
}
```

第一版不将大量 `info` 字段塞入 Replay Buffer，而是在日志 / episode summary 记录诊断信息。

### 2.4 terminated / truncated 冻结语义

R9 明确采用：


| Env 结果                         | `dones` | `masks` | 是否 reset | 语义                       |
| ------------------------------ | ------- | ------- | -------- | ------------------------ |
| 普通 step                        | `False` | `1.0`   | 否        | 可 bootstrap              |
| `terminated=True`              | `True`  | `0.0`   | 是        | 任务 MDP 终止，不 bootstrap    |
| `truncated=True` 且未 terminated | `False` | `1.0`   | 是        | 时间/安全/新鲜度截断，保留 bootstrap |
| 两者同时                           | `True`  | `0.0`   | 是        | terminated 优先            |


即：

```python
done = bool(terminated)
mask = np.float32(0.0 if terminated else 1.0)
episode_end = bool(terminated or truncated)
```

> 注意：`dones` 不等于 `episode_end`。如需归档轨迹边界，单独记录 `terminated/truncated/episode_end`，不改变 Replay Buffer 冻结 schema。



### 2.5 干预分流语义

```text
无 info["intervene_action"]
  actions = policy_action
  insert actor_env only

有 info["intervene_action"]
  actions = copy(info["intervene_action"])
  insert actor_env
  insert actor_env_intvn
```

必须保证：

- `transition["actions"] == info["intervene_action"] == WA2Env 实际执行 action`；  
- `actor_env` 数量 = 总 transition 数；  
- `actor_env_intvn` 数量 = `intervene_action` 出现的步数；  
- `intervention_count` 是干预段数，`intervention_steps` 是干预步数；  
- 一个连续 deadman 段只增加一次 `intervention_count`。



### 2.6 Agentlace 上传成功判定

Agentlace `0.1.3` 客户端应使用本地修正 wheel，但 R9 不能仅依赖 `client.update()` 返回值判定成功。权威证据是：

1. `client.update()` 成功；
2. Server `actor_env` / `actor_env_intvn` 实际计数达到期望；
3. Server `last_update_id` 与 Client latest id 一致；
4. Server 中的 transition schema/hash 检查通过；
5. 不允许丢失、重复或静默跳过干预队列。

本地端口固定沿用上游：

```text
127.0.0.1:5588  transition / request
127.0.0.1:5589  network broadcast
```



### 2.7 上传节奏与 fail-closed

当前上游 `train_rlpd.py` 只在 episode 结束时 `client.update()`，且没有把上传失败绑定到真机 stop。R9 必须改为可验收的策略：

```text
upload_every_steps = 10         # 建议默认；可配，不得 >50
network_max_age_s = 5.0         # 真机模式必须有参数广播新鲜度
max_consecutive_upload_failures = 1   # 真机 fail-closed
client timeout_ms = 3000
```

任一条件满足时：

```text
client.update / confirm 失败
Server 请求超时
network params 超龄
callback 替换参数失败
Actor 异常 / Ctrl+C
Env stale / singular / safety truncated
```

必须执行：

```text
停止 step 循环
不再发布任何新动作
env.close() → WA2ServoSession.stop() + clear()
client.stop()
写明确 fault reason
真机不自动无限重连
```



### 2.8 参数广播语义

dummy Server 不发送 `{"step": 1}` 这类测试字典给正式 Actor callback，而必须发送与当前 SAC agent 结构兼容的 `agent.state.params`。Actor 记录：

```text
network_update_count
last_network_update_monotonic
params_tree_signature/hash（不在普通日志展开整个参数树）
```

R9 只验证一次或少量广播和 callback，不执行 Learner 更新。

### 2.9 真机 Gate 的运动上限

- policy 固定为 6D 零动作；  
- 只有 SpaceMouse deadman + 有效轴时发生运动；  
- 每步仍由 Env 限制为 `1 mm / 0.25°`；  
- 单次 Gate 建议总计 `≤20 mm / ≤2°`；  
- 不执行完整抓取，不追求 reward/成功；  
- 默认 `--skip-reset-motion`；若需场景 reset，必须单独设置 R5 确认变量；  
- 真机前必须确认物理急停可达、工作区清空、无其它 ServoL 发布者。

## 3. 分步实施计划


| Step | 内容                                     | 产出               | 运动风险             |
| ---- | -------------------------------------- | ---------------- | ---------------- |
| 0    | R8 回归、wheel/hash、端口基线                  | preflight        | 无                |
| 1    | transition builder + 终止/截断单测           | unit tests       | 无                |
| 2    | fake env 100 步 + 合成干预 + dump/reload    | offline Gate     | 无                |
| 3    | localhost Server/Client 双 store 上传     | Agentlace Gate   | 无                |
| 4    | 兼容 SAC params 广播/callback              | network Gate     | 无                |
| 5    | Server 停止、异常、SIGINT 安全生命周期             | fault Gate       | dry-run/Mock     |
| 6    | 真 ROS 状态+图像+Joy readonly transition    | readonly Gate    | 无运动              |
| 7    | 零 policy + SpaceMouse 真机小范围 transition | live Gate        | **有运动**          |
| 8    | live 断 Server / Ctrl+C stop+clear 验证   | fail-closed Gate | **有运动，零 policy** |
| 9    | 回归、数据/hash/日志归档                        | R9 验收记录          | 无                |


阶段放行规则：

```text
Step 1～5 全 PASS → 才可进 readonly
readonly PASS       → 才可进 live-zero
live-zero PASS      → 才可做 live fault-stop
```

## 5. 验收标准（Gate 清单）

以下全部勾选后才能标记 **R9 GATE: PASS**。

### 5.1 前置与回归

- [ ] R8 验收记录存在且判定 PASS  
- [ ] `wa2_bottle_pick` mapping、bundle hash、space hash 已记录

- [ ] R1～R8 相关离线单测 / Gate 无回归  
- [ ] 5588/5589 启动前无未知占用进程  



### 5.2 Transition 语义

- [ ] 连续至少 100 条 transition schema 一致  
- [ ] observations/actions/next_observations 无 NaN/Inf  
- [ ] action shape `(6,)`、dtype `float32`、范围属于 action space  
- [ ] normal/terminated/truncated/both 四种情况单测通过  
- [ ] terminated → `dones=True, masks=0`  
- [ ] truncated-only → `dones=False, masks=1`，但 episode reset  
- [ ] dump 可重新加载，数量/schema/hash 一致  



### 5.3 干预与双 buffer

- [ ] 无干预 transition 只进 `actor_env`  
- [ ] 有干预 transition 同时进 `actor_env` / `actor_env_intvn`  
- [ ] transition action 等于 `intervene_action` 与实际执行 action  
- [ ] Server `actor_env` 数量等于总步数  
- [ ] Server `actor_env_intvn` 数量等于干预步数  
- [ ] intervention count/steps 与人工/合成记录一致  
- [ ] 无重复、静默丢失或队列溢出  



### 5.4 Agentlace 本地闭环

- [ ] Client 仅连接 `127.0.0.1`  
- [ ] Server 注册 `actor_env` / `actor_env_intvn` 两个 store  
- [ ] 每 10 步或更快执行上传，不再只等 episode 结束  
- [ ] Server 计数与 `last_update_id` 作为上传成功证据

- [ ] Actor callback 成功处理至少一次 network update

- [ ] Actor 主循环全程在 `try/finally` 生命周期中  
- [ ] Server 断开后在一个 upload 周期 + timeout 内停止  
- [ ] network params 超龄后不继续真机 step  
- [ ] Actor 异常 / Ctrl+C 后 `env.close()` / `client.stop()`  
- [ ] Env stale/singular/safety truncated 后不再发布新动作  
- [ ] 真机故障 Gate 中 `stop_ok=True` 且 `clear_ok=True`

## 6. 风险与对策


| 风险                                 | 对策                                                                |
| ---------------------------------- | ----------------------------------------------------------------- |
| 未训练 SAC 直接发真机动作                    | live 脚本强制 `--policy zero`；其它 policy 立即拒绝                          |
| 上游只在 episode 结束上传                  | 增加最多 10 步的周期上传；Server count/last id 确认                            |
| `client.update()` 布尔值假阳性           | 不单独依赖返回值；必须验 Server 实际数量和 last id                                 |
| Server 断开后 Actor 继续旧策略             | 上传/network watchdog + fail-closed + stop/clear                    |
| 断线后自动重连突然恢复动作                      | 真机不自动恢复；须人工重启和重过 preflight                                        |
| `truncated` 被当作 terminated         | 独立单测冻结 `done=False, mask=1, reset=True`                           |
| 干预 action 没写入普通 buffer             | 统一 transition builder；干预步先替换 action 再双写                           |
| 只写干预 buffer，普通 buffer 漏记           | 所有步必入 `actor_env`；干预另外入 intvn                                     |
| QueuedDataStore 容量太小导致静默丢数据        | Gate 容量 > 最大未上传步数；周期上传；序号连续性校验                                    |
| network payload 结构不兼容              | dummy Server 发真实 `agent.state.params`；callback 前比较 tree signature |
| `info["episode"]` 在非 episode 边界不存在 | 只在 terminated/truncated 后读 episode summary；平时不假设存在                |
| readonly 数据被当作真执行数据                | summary 强制 `read_only=true`；单独输出目录；不并入训练 buffer                   |
| 两个 ServoL 发布者                      | 启动前 pgrep/ROS 检查；teleop 与 Actor 互斥                                |
| 真机故障注入时还在干预                        | 先松 deadman，确认 zero action，再停 Server / Ctrl+C                      |
| 为 R9 修改上游后破坏 Franka                | WA2 安全门控显式开启；上游改动最小化；记录 dirty diff                                |
| 正式 `train_rlpd.py` 对空 demo 的限制     | R9 不运行 Learner 训练 loop；dummy Server 独立实现；R10 再处理 demo/training 前置 |

| callback params tree mismatch                 | Server 发了测试 dict 或不同 agent 结构；重用同 task 的 SAC params          |
| Server 计数多于 Actor                             | 可能复用了旧 Server/store；每次 Gate 用新进程和空 store                     |
| Server 计数少于 Actor                             | 上传周期/最后 flush、queue 容量或断线；检查 last id                         |
| readonly 中机器人运动                               | 立即急停；说明误走 `read_only=False`，R9 FAIL                          |
| readonly `info` 无 `action_ignored_for_motion` | Env/wrapper 层级或检查脚本错误                                        |
| live 脚本接受 `--policy sac`                      | 安全门禁实现缺失；立即停止，R9 FAIL                                        |
| `info["episode"]` KeyError                    | 只能在 terminated/truncated 边界读 RecordEpisodeStatistics summary |
| Server 断开但 Actor 继续 step                      | watchdog/fail-closed 未生效；真机 R9 FAIL                          |
| Ctrl+C 无 `stop_ok/clear_ok`                   | Actor 未在 finally 关闭 Env 或取证时机错误                              |
| SpaceMouse 干预为 0                              | 检查 Joy hz、deadman 按钮和 teleop 互斥                              |
| 累计运动超限                                        | 脚本应先于 Env 大盒主动 fail-closed；停机并判 R9 FAIL                      |
