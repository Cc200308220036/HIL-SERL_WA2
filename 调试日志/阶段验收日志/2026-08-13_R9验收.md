## 4. 实施相对方案的调整

1. **R9 GATE 不改** `train_rlpd.py`，权威入口为 `verify_r9_*.py` + `r9_dummy_trainer_server.py`。
2. fake 合成干预只在脚本外包 `WA2SpacemouseIntervention` + `inject`，不破坏 R8 `fake_env` 隔离。
3. 上传成功以 Server store 计数 / `last_update_id` 为准，不信 `client.update()` 布尔值。
4. dummy Server **不** `make_sac_pixel_agent`；params 由 Actor pickle，Server 加载并周期广播。
5. readonly/live 用人时窗 `--min-seconds 20`，不用 100 步 × 50 Hz。
6. Agentlace Broadcast/ZMQ 线程可能挡住解释器退出，Gate 脚本末尾 `os._exit`。
7. `start_spacemouse_joy.sh` 里 `spacenavd -d -v` 遇 X11 授权可能前台卡住；本次改为已有 `spacenavd` 后单独起 `spacenav_node`。

### 7.5 live-zero / 断连 / SIGINT（会动或会进 ServoL）

**注意事项**

- 只能 `--policy zero`，必须 `export R4_CONFIRM=YES`。未训练 SAC 不准控臂。
- 与 `spacemouse_wa2_teleop.py` **互斥**。
- 默认 `--skip-reset-motion`，不要随便 `--with-reset`。
- 累计位移上限 **20 mm**；轻推 **2～3 秒** 即可（≥10 步）。推太久会 `motion_budget_translation`。
- Client 只能 `127.0.0.1`。每次重跑前必须停掉旧 dummy Server，否则计数对不上。
- 不要用 `pkill -f r9_dummy_trainer_server.py`（会误杀当前 bash）。先 `ps` 再 `kill <PID>`。
- 真机 SIGINT 不要打到外层 `docker exec`，只对 Python：`kill -INT <python_pid>`。
- 急停：物理急停，或 `rosservice call /zj_humanoid/upperlimb/stop "{}"`。
- 打印 `PASS` 后进程还在：看最后一行判定，再 `kill` 掉即可。
