## 4. Env 用法（R7）

```python
from hilserl_wa2.envs.wa2_env import WA2Env
from hilserl_wa2.interventions.wa2_spacemouse_intervention import (
    WA2SpacemouseIntervention,
)

env = WA2Env(fake_env=False, read_only=False, scene_name="bottle_desktop")
env = WA2SpacemouseIntervention(env)  # 外层；勿与 teleop 同开
obs, info = env.reset()
obs, r, term, trunc, info = env.step(policy_action)
if info.get("intervened"):
    # 使用 info["intervene_action"] 写入 intervention buffer（R9）
    ...
env.close()
```

| 条件 | 行为 |
|---|---|
| 无 deadman / Joy stale | 执行 policy；无 `intervene_action` |
| deadman + 有效轴 | `intervene_action ==` 实际 step 动作 |
| 手按钮 | 仅记入 info 侧状态，不扩 7D action |
