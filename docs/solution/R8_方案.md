## 1. 目标与非目标

### 1.1 目标

1. 让 HIL-SERL 上游通过 `--exp_name=wa2_<task_id>` 加载对应 WA2 任务；`CONFIG_MAPPING` **扫描** `hilserl_wa2/configs/tasks/*.yaml` 自动注册，新任务不改 `mappings.py`；  
2. 将「机器人开局标定」与「HIL-SERL 观测 / Wrapper / 训练参数」分离：  
   - `configs/scenes/<scene>.yaml`：reset/home/工作区/超时 / **episode** 步数；  
   - `configs/tasks/<task>.yaml`：实验观测、Wrapper、训练参数及所引用的 scene/camera/SpaceMouse；  
3. 用一个 `make_wa2_environment(...)` 统一构造 Actor 与 Learner Env，包装顺序仅维护一份，YAML 只允许开关、不允许重排；  
4. `get_environment(fake_env=True)` 不初始化 ROS、SpaceMouse、RealSense、ServoL 或机器人状态；  
5. Actor 与 Learner 最终 `observation_space` / `action_space` 可序列化并严格一致；Intervention Wrapper **不得**改变 space；  
6. 在 `hil-actor` 中完成 SAC pixel agent 初始化和 Replay Buffer 单条 transition 插入 / 采样；  
7. 对任务、场景、Env 契约、相机和 SpaceMouse 配置生成组合 SHA-256，为 R9/R10 版本对齐提供依据；  
8. 用第二个 Mock 任务 `r8_mock_alt` 验证：只加 YAML、不改 Python 也能出现在 `CONFIG_MAPPING`；  
9. 第一份真实任务 `bottle_pick` 作为 **测试真机实验流程的第一个任务**（R8 只做 fake_env / agent / buffer；真机 transition 仍归 R9）。

`WA2_TASK` 仅为可选覆盖：与 `--exp_name` 解析出的 `task_id` 不一致时必须拒绝，不得静默改任务。

### 1.2 非目标

| 不做 | 归属 |
|---|---|
| 真机 Actor 持续采 transition | R9 |
| `actor_env` / `actor_env_intvn` 真实 Agentlace 分流 | R9 |
| Orin Actor ↔ 笔记本 Learner 跨机通信 | R10 |
| 示范采集 | R11 |
| Reward Classifier 训练与在线 reward | R12 |
| 修改 6D action 维度 / shape / 坐标系 | 需回到 R1 契约变更并重跑相关 Gate |
| 用任务 YAML 扩大单步物理限幅 | 禁止；安全上限属于 Env 契约 |
| 为每个任务复制一份 `config.py` | 禁止；本阶段要解决的正是可复用性 |
| 为迁就 `train_rlpd.py` 去改上游 classifier 调用 | 禁止；R8 在 `get_environment` 内 **绕过** |

## 2. 架构与冻结语义

### 2.1 配置分层

```text
WA2 Env 契约（极少改）
  action/observation shape、dtype、坐标系、单步限幅、新鲜度
  包内权威：hilserl_wa2/configs/wa2_env_contract.yaml
                  │
                  ├─ 硬件运行配置（换硬件才改）
                  │    cameras/<name>.yaml
                  │    spacemouse/<name>.yaml
                  │
                  ├─ 场景配置（换开局/工作区时改）
                  │    scenes/<scene>.yaml
                  │    reset/home/TCP/超时/episode.max_steps
                  │
                  └─ 任务实验配置（日常新任务入口）
                       tasks/<task>.yaml
                       image/proprio keys、wrapper、agent、训练参数
                       CONFIG_MAPPING key = wa2_<task_id>
```

第一个真机实验流程任务：

```text
task_id  = bottle_pick
exp_name = wa2_bottle_pick
scene    = bottle_desktop     # R5 已验收，不改场景文件名
```

`task_id` 与 `scene_id` **允许不同**：任务描述「做什么」，场景描述「开局标定在哪」。后续新任务复制两份 YAML 并改引用即可。

冻结边界：

- 任务 YAML 可以缩小任务限制，不得扩大 Env 契约的物理安全上限；  
- action 从 6D 改 7D、改 shape/dtype/坐标系不是「新任务」，必须升级契约并回归 R1～R7；  
- 运行配置位于 `catkin_ws/src/hilserl_wa2/configs/`，不依赖容器默认不可见的仓库根 `configs/`；  
- `env.contract: default` **只**解析为包内 `hilserl_wa2/configs/wa2_env_contract.yaml`。

### 2.2 通用环境数据流

```text
--exp_name=wa2_bottle_pick
         │
         ▼
  CONFIG_MAPPING 自动扫描 tasks/*.yaml
         │
         ▼
    WA2TrainConfig(task_id=bottle_pick)
         │ load task YAML + validate
         ▼
  make_wa2_environment(task, fake_env)
     │
     ├─ fake_env=True  → WA2Env(MockRobot + MockCameras)
     │                    不 import / 不包装 SpaceMouse
     │
     └─ fake_env=False → WA2Env(ROS + cameras + ServoL)
                          → WA2SpacemouseIntervention（按 YAML 开启；惰性 import）
         │
         ▼
   SERLObsWrapper(proprio_keys)      # 顺序固定
         │
         ▼
   ChunkingWrapper(obs_horizon, act_exec_horizon)
         │
         ▼
 {state, head, wrist} + action[6]
```

`save_video=True` 在 R8 **忽略**（不打开相机、不写视频）。  
`classifier=True` 在 `reward.mode=constant_zero` 且 `classifier_keys=null` 时 **绕过**：打 warning，不加载 checkpoint。上游 `train_rlpd.py` 写死 `classifier=True`，不得因此修改上游或拒绝构造 Env。  
`process_demos` 提供恒等/flatten 桩，供 R11 使用，R8 不采集 demo。

### 2.3 冻结的第一版 SERL 接口

`WA2Env` 原始观测：

```python
{
    "state": {
        "tcp_pose": float32[7],
        "tcp_vel": float32[6],
        "joint_pos": float32[8],
        "hand_joints": float32[6],
    },
    "images": {
        "head": uint8[128, 128, 3],
        "wrist": uint8[128, 128, 3],
    },
}
```

`SERLObsWrapper` + `ChunkingWrapper(obs_horizon=1)` 后：

```python
{
    "state": float32[1, 27],
    "head": uint8[1, 128, 128, 3],
    "wrist": uint8[1, 128, 128, 3],
}
action = float32[6] in [-1, 1]
```

> `state` 的 27 维来自 `7+6+8+6`。由于 `ChunkingWrapper(obs_horizon=1)` 仍会增加 horizon 维，最终 shape 是 `[1,27]`，不是 `[27]`。

### 2.4 fake_env 硬件隔离（强制）

`get_environment(fake_env=True)` 必须：

- 不调用 `rospy.init_node`，不访问 ROS Master；  
- 不**构造** `WA2StateMonitor`、`WA2Cameras`、`WA2ServoSession`；  
- 不启动 `JoyWatchdog.start_ros()` / 不包装 SpaceMouse；  
- 不打开 RealSense 或读取真实 topic；  
- 不 import / 构造 Franka Env、Franka server URL 或上游 HID `SpaceMouseExpert`；  
- 仍根据同一份 Env 契约、任务 YAML 和 wrapper 顺序产生与 Actor 相同的 spaces。

隔离 Gate **不以** `sys.modules` 是否出现过 `rospy` 为失败条件（容器可能已 source ROS，或其它测试污染同一进程）。判定：

```text
未 rospy.init_node / rospy.core.is_initialized() 为 False
未构造 WA2StateMonitor / WA2Cameras / WA2ServoSession 实例
Intervention 仅在 fake_env=False 分支惰性 import
factory 禁止 from hilserl_wa2.interventions import ... 的包级大包导入
```

### 2.5 任务选择语义（自动注册）

#### 映射规则

扫描目录（容器权威）：

```text
/root/catkin_ws/src/hilserl_wa2/configs/tasks/*.yaml
```

忽略：`_TEMPLATE.yaml`、文件名以 `_` 开头的文件。

每个合法 YAML：

```text
文件名 stem = task_id
CONFIG_MAPPING 键 = "wa2_" + task_id
例：tasks/bottle_pick.yaml → --exp_name=wa2_bottle_pick
```

`mappings.py` **只改一次**：

```python
from experiments.wa2.config import discover_wa2_mapping

CONFIG_MAPPING = {
    "ram_insertion": RAMInsertionTrainConfig,
    "usb_pickup_insertion": USBPickupInsertionTrainConfig,
    "object_handover": ObjectHandoverTrainConfig,
    "egg_flip": EggFlipTrainConfig,
    **discover_wa2_mapping(),
}
```

禁止为每个任务手写 `"wa2_bottle_pick": ...`。扫描失败（YAML 损坏、task_id 与文件名不符）应在 import/discover 时立即报错。

不注册裸键 `"wa2"`，避免 W&B / checkpoint / demo 路径在多任务间碰撞。

#### 解析优先级

```text
1. --exp_name=wa2_<task_id>     → task_id（主入口，W&B/checkpoint 用此名）
2. 可选环境变量 WA2_TASK        → 必须与 1 的 task_id 相同，否则拒绝
3. 启动脚本可接受第一个参数      → 转成 --exp_name=wa2_<arg>
```

规则：

1. `task_id` 只能是 `[a-z0-9_]+`，禁止 `../` 路径穿越；  
2. 启动时打印 `exp_name`、`task_id`、所有解析后的绝对配置路径和组合 hash；  
3. Actor/Learner 的 `exp_name` 或 `config_bundle_hash` 不同时，R10 必须拒绝建立训练会话；  
4. `WA2_TASK` 未设置时，只要 `--exp_name=wa2_<task_id>` 合法即可运行（启动脚本若无参数且无 `WA2_TASK` 则拒绝）。

### 2.8 任务 YAML 建议 schema

```yaml
schema_version: "1"
task_id: bottle_pick
display_name: "桌面抓瓶抬起（真机实验流程第一个任务）"

env:
  scene: bottle_desktop          # → configs/scenes/bottle_desktop.yaml
  contract: default              # → 包内 configs/wa2_env_contract.yaml
  camera: head_wrist             # → configs/cameras/head_wrist.yaml
  spacemouse: default            # → configs/spacemouse/default.yaml

observation:
  image_keys: [head, wrist]
  proprio_keys: [tcp_pose, tcp_vel, joint_pos, hand_joints]

action:
  mode: left_arm_6d

wrappers:
  intervention: true             # fake_env=True 时强制不包装
  serl_obs: true
  obs_horizon: 1
  act_exec_horizon: null

reward:
  mode: constant_zero
  classifier_keys: null          # R8 必须为 null；train_rlpd 传入 classifier=True 时绕过

training:
  agent: drq
  setup_mode: single-arm-fixed-gripper
  encoder_type: resnet-pretrained
  discount: 0.97
  batch_size: 256
  # 训练总步（Actor/Learner 循环），默认 1000000；禁止与 scene.episode.max_steps 混用
  max_steps: 1000000
  replay_buffer_capacity: 200000
  random_steps: 0
  training_starts: 100
  steps_per_update: 50
  buffer_period: 1000
  checkpoint_period: 5000
```

步数语义（禁止混名）：

| 字段 | 所在文件 | 含义 |
|---|---|---|
| `episode.max_steps` | `scenes/*.yaml` | 单局 Env 截断（抓瓶已冻结 1200） |
| `training.max_steps` | `tasks/*.yaml` | 训练循环总步（默认 1e6） |
| `max_traj_length` | 上游 DefaultTrainingConfig | `train_rlpd.py` **不使用**；R8 不从 YAML 覆盖，以免和 episode 混淆 |

校验原则：

- 缺少必填字段、未知顶层 key、错误 dtype/range 要在启动时立即报错；  
- `task_id` 必须与文件名 stem 一致；  
- 第一版仅接受 `action.mode=left_arm_6d`；  
- `image_keys` / `proprio_keys` 必须存在于 `WA2Env.observation_space`；  
- `obs_horizon >= 1`；第一版 `act_exec_horizon` 保持 `null`；  
- `classifier_keys` 在 R8 必须是 `null`；`get_environment(classifier=True)` **绕过**加载，不伪装 Reward Classifier 已完成；  
- 任务 YAML 不得包含 Franka server URL、RealSense 序列号或 ServoL 安全上限；  
- YAML 不得提供「扩大单步 mm/deg」字段。

`r8_mock_alt.yaml` 冻结差异（可复用性 Gate）：

```text
必须保持不变：image_keys、proprio_keys、obs_horizon、act_exec_horizon、action.mode
允许不同：scene 引用、display_name、training.discount、training.batch_size
断言：space_hash 相同；task_hash 与 config_bundle_hash 不同
```

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 每个任务复制 Python Config，后续漂移 | 扫描 YAML 注册 `wa2_<task_id>`；一个 factory；任务只用 YAML |
| 多任务抢同一 `exp_name=wa2` | 不注册裸键 `wa2`；W&B/checkpoint 使用完整 `wa2_bottle_pick` |
| 任务配置与场景标定混在一起 | `tasks/` 与 `scenes/` 分层；抓瓶任务引用已验收 `bottle_desktop` |
| `training.max_steps` 被写成 1200 | 文档与 schema 注释区分 episode vs 训练总步 |
| Actor/Learner 选了不同任务 | 两侧都用 `--exp_name=wa2_<id>`；打印 bundle hash；R10 建连前比较 |
| `WA2_TASK` 与 `exp_name` 不一致 | 启动时交叉校验，不一致则拒绝 |
| fake_env 意外启动 ROS/相机/Joy | factory 先分支 backend；惰性 import；查构造与 `init_node` |
| 只比较 shape，漏掉 dtype/bounds | 确定性 space serializer 同时序列化 key/shape/dtype/low/high |
| Intervention 将来改 obs 导致两侧 space 分裂 | R8 断言 Intervention 不改变 space |
| `ChunkingWrapper` 增加 horizon 维后误判 state shape | R8 冻结最终 shape 为 `(1,27)`；测试按包装后 space |
| 上游 Config 意外 import Franka | WA2 `config.py` 只 import WA2 factory 和通用 training base |
| `train_rlpd.py` 写死 `classifier=True` | `constant_zero` 时绕过，不改上游 |
| 预训练 ResNet 触发外网下载 | 使用已下载的 `~/.serl/resnet10_params.pkl`；缺失则按 §4.8 一次性 curl，禁止 `resnet` 回退 |
| 本地笔记本测试被当作 Orin Gate | 验收文档必须记录执行环境；正式 PASS 仅来自 `hilserl/hil-actor` |
| 运行时依赖仓库根 `configs/` | 容器权威运行配置位于 `catkin_ws/src/hilserl_wa2/configs/` |
