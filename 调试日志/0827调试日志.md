## 异步踩坑（2026-08-27）

`WA2_CLASSIFIER_INFER_MODE=async` 若与 Servo 窗并发跑 JAX，Orin 上会
`SERVO_FAULT_STOP reason=action_window_timeout`（GIL/GPU 争用）。

已改为 **窗前 join**：JAX 不得与 5-tick 窗重叠。因此 async 几乎不再比
decimate 更能减 `arm_idle`；**请继续用默认 decimate**。

```bash
unset WA2_CLASSIFIER_INFER_MODE
# 若要再压会话内开销：
export WA2_CLASSIFIER_SESSION_EVERY_N=3
```
