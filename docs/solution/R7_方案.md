## 1. 目标与非目标

### 1.1 目标

1. 把已验证的 `/spacenav/joy` 转为与 `WA2Env.action_space` **完全一致**的 6D action；  
2. 新建 **WA2 专用** Gymnasium `ActionWrapper`（建议名 `WA2SpacemouseIntervention`），**不**使用 Franka HID `SpaceMouseExpert`；  
3. 复用已有 `SpaceMouseInputProcessor` 的 axis map/sign、deadzone、滤波、组间互斥 / 主轴锁定；  
4. 干预语义：  
   - 无 deadman 或无效输入 → 原样执行 **policy action**；  
   - deadman + 有效输入 → **覆盖**为 SpaceMouse action，并写入 `info["intervene_action"]`；  
5. Wrapper **禁止**直接调用 ServoL / hand Service；唯一出口仍是内层 `WA2Env`；  
6. 与手动遥操脚本互斥：Actor/干预链路运行时 **不得**同时跑 `spacemouse_wa2_teleop.py`；  
7. 离线合成 Joy 映射 Gate + 真机小范围方向一致性 Gate。

### 1.2 非目标

| 不做 | 归属 |
|---|---|

## 2. 架构与冻结语义

### 2.1 控制权原则（强制）

```text
【错误】HIL 正式链路
  spacemouse_wa2_teleop.py ──ServoL──┐
  Actor / Env.step ──────────ServoL──┴→ 双发布者竞争

【正确】HIL 正式链路
  /spacenav/joy
       │
       ▼
  WA2SpacemouseIntervention (ActionWrapper)
       │  覆盖时写 info["intervene_action"]
       ▼
  WA2Env.step(action) → WA2ServoSession → 唯一 ServoL
```

手动遥操脚本仅作独立工具与映射基准；**与 Actor/干预 Env 互斥**。

### 2.2 数据流

```text
policy_action ∈ [-1,1]^6
        │
        ▼
WA2SpacemouseIntervention.step(policy_action)
        ├─ 读最新 Joy（或注入合成 Joy）
        ├─ deadman?（建议 buttons[1]，与遥操一致）
        ├─ Joy age ≤ joy_max_age_s ?
        ├─ SpaceMouseInputProcessor → command[6]
        │
        ├─ 未干预：exec = policy_action
        │         不写 intervene_action
        └─ 干预：  exec = clip(sm_action)
                  info["intervene_action"] = exec.copy()
                  info["intervened"] = True
        │
        ▼
WA2Env.step(exec)   # 限幅 / ServoL / 图像 / reset 语义不变
```

### 2.3 与 Franka Wrapper 的差异

| 项 | Franka `SpacemouseIntervention` | WA2（本方案） |
|---|---|---|
| 输入 | HID `SpaceMouseExpert` | ROS `/spacenav/joy` |
| 映射 | 上游默认 | **复用** `spacemouse_input.py` 标定 |
| deadman | 常靠范数阈值 | **显式 deadman 键**（与 0810 遥操一致） |
| 手部 | 常拼 7D | 第一版 **6D**；按钮进 `info["sm_left"]`/`sm_right` |
| 动作出口 | 仍经 Franka Env | 必须经 `WA2Env`，Wrapper 零 Service |

### 2.4 冻结交互语义（第一版）

| 项 | 取值 |
|---|---|
| Joy topic | `/spacenav/joy` |
| deadman | `buttons[1]`（左键，按住才允许覆盖） |
| 右键 | `buttons[0]` → 仅 `info` 记录（抓握意图占位；不扩 action） |
| 有效干预 | deadman **且** `‖command‖ > intervene_eps`（建议 `1e-3`） |
| Joy stale | `joy_max_age_s` 建议 `0.2`；过期 → **强制不干预**，用 policy action |
| action 空间 | `float32[6]`，`[-1,1]`，与契约一致 |
| 主导轴 | 沿用现有组间互斥 + 组内主轴（丝滑度优化见 §7，可选） |

已标定轴符号（与 `SpaceMouseInputConfig` 默认一致，勿擅自改）：

```text
axis_map  = (0,1,2,3,4,5)
axis_sign = (-1,-1,+1, +1,-1,-1)
# 输出顺序: dx,dy,dz,droll,dpitch,dyaw  ↔ Env action
```

### 9.6 常见故障

| 现象 | 排查 |
|---|---|
| `package 'spacenav_node' not found` | 未 `source /root/catkin_ws/devel/setup.bash` |
| Joy `no new messages` | 跑 `start_spacemouse_joy.sh`；看 `/tmp/spacenav_node.log` |
| `R7_LIVE: FAIL — teleop is running` | 停 teleop；再 `stop` 服务 |
| intervened 一直为 0 | 左键 deadman=`buttons.deadman`（默认 1） |
| 方向不对 | 改 YAML `input.axis_sign`，Intervention 与 teleop 会一起变 |
| `No module named hilserl_wa2` | `export PYTHONPATH=/root/catkin_ws/src:$PYTHONPATH` |
